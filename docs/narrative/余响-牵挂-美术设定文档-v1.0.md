# 一、项目概述

## 1.1 一句话介绍

> 一款 2D 横版叙事解谜游戏：一对母女之间有一根看得见的"牵挂线"，玩家操控母女两人，利用这根线的张力、锚定与拉力，走过"离家"到"和解"的四章旅程。

## 1.2 基本信息

| 项    | 内容                      |
| ---- | ----------------------- |
| 类型   | 2D 横版卷轴 / 叙事解谜 / 双角色合作  |
| 视角   | 横版侧视（含少量定点第一人称过场，见 6.4） |
| 篇幅   | 4 章，单章 15–25 分钟         |
| 平台   | PC（网页原型验证中，后续移植引擎）      |
| 目标情绪 | 克制的、日常的、最后决堤的           |

## 1.3 章节结构（美术只需记住色彩走向）

| 章   | 标题     | 内容              | 画面基调           |
| --- | ------ | --------------- | -------------- |
| 序章  | （开场动画） | 缝纫机与红线          | 暖金             |
| 第一章 | 离家     | 23 岁女儿搬家，发现线的存在 | **冷灰蓝**（现代）    |
| 第二章 | 第一次放手  | 闪回：女儿 7 岁，母女上学路 | **暖金**（2009 年） |
| 第三章 | 一起走一段  | 双角色合作搬运行李       | 冷灰蓝，线是唯一热源     |
| 第四章 | 线的尽头   | 冷战、霜断、和解        | 冷→失色→回暖        |

**全书色彩总规则：回忆是暖的，现在是冷的，而线的颜色在两个时代里一模一样。**

# 二、世界观与视觉基调

## 2.1 城市原型：哈尔滨（不明说）

*   城市气质锚定**哈尔滨**，但游戏内不出现任何地名，只保留气质，"北方小城"。

*   选址理由：满城都是"线"——电线、晾衣绳、冰溜子、有轨电车线。城市的视觉语言天然与主题同构。

*   场景原型：**老道外·中华巴洛克街区**。这种建筑是"西洋骨架中国魂"（欧式立面 + 中式院落生活），与母女两代人的关系同构：骨架是旧的，日子是新的。

*   关键实景特征（建模/绘制依据）：

    *   清水砖墙，欧式线脚与浮雕，墙皮斑驳；

    *   二楼挑出的小阳台，铁艺栏杆；

    *   拱窗、高门洞，门洞内是天井院落；

    *   街道窄，晾衣绳横穿街道，从这家阳台拉到那家窗框；

    *   铁艺路灯（绿色灯座 + 玻璃灯罩）——**第二章关键道具**；

    *   冬季：屋檐冰溜子、窗上冰花、路面残雪与煤灰。

## 2.2 双时代设定

|      | 2009 年（第二章闪回） | 2020 年代（一、三、四章） |
| ---- | ------------- | --------------- |
| 调色   | 暖金、橙黄、略过曝     | 冷灰蓝、低饱和         |
| 光线   | 早晨的斜光、路灯暖光    | 阴天、白炽灯、LED 冷光   |
| 招牌   | 手写美术字、红蓝白编织袋  | 打印灯箱、连锁便利店      |
| 路面   | 砖石、煤渣         | 柏油、共享单车         |
| 声音参照 | 自行车铃、广播、早点摊   | 地铁报站、手机提示音      |

【待定】闪回是否叠加轻微胶片颗粒/暗角滤镜

## 2.3 三条视觉要求

1.  **线永远是画面里最重要的东西。** 任何场景、任何构图中，观众视线必须能找到线。背景细节再丰富，也不能和线抢戏。

2.  **冷画面里的唯一热源是线。** 第一章的冷灰蓝房间里，线是唯一发光、唯一带红色的物体。

3.  **画"日子"，不画"惨"。** 下岗、丧夫、冷战都是背景，画面里只能看到这些事的**痕迹**（补过的围裙、桌上的旧相框），不出现任何直白诉苦的画面。

# 三、核心视觉资产：牵挂线

线是这款游戏的第一主角，按角色资产的标准制作。

## 3.1 基础形态

*   **颜色**：红色。不是鲜红，是缝纫线那种略带岁月感的**棉线红**（参考值 #C0392B \~ #A93226 区间）。

*   **质感**：棉线，有轻微毛边，不是钢丝绳也不是激光。近景可见纤维感。

*   **发光**：始终带微弱自发光，冷调场景里更明显。发光的是线本身，不向环境投射强光（不用做法线光源，用叠层即可）。

## 3.2 连接方式（血管式核心视觉）

*   线**连接在两人的手心**：像血管一样，从手腕内侧的皮肤下浮现出来，延伸至掌心——仿佛是从身体里长出来的，不是系上去的。

*   皮下段的表现：手腕内侧皮肤下透出**淡淡的红色脉络**，向掌心汇聚，线在掌心穿出皮肤。穿出处没有伤口、没有血——它像静脉一样自然，是身体的一部分。

*   近景/演出镜头可以看到皮肤下脉络的微光随情绪轻轻搏动（像心跳）；远景 gameplay 中只需保证掌心有线出来即可。

*   线的连接点不做插头、锁扣、绳结等任何机械结构。它就是"长在那里"。

*   设计意图：牵挂不是外部束缚，是**长进身体里的东西**。

## 3.3 四种状态（对应玩法，必须可一眼区分）

| 状态     | 表现                   | 触发       |
| ------ | -------------------- | -------- |
| **松弛** | 自然下垂呈悬链线，轻微摆动，暗淡     | 两人距离近    |
| **张力** | 拉直，亮度提升，微微绷紧颤动       | 距离拉大     |
| **极限** | 剧烈高频震动，发红光，画面边缘轻微泛红  | 超过距离上限   |
| **锚定** | 一端钉在角色所在点，该端发出稳定的暖光晕 | 角色主动固定自己 |

# 四、角色设定

## 4.1 余秀兰（母亲）

### 基本信息

*   48 岁（主线）/ 33 岁（第二章闪回）。

*   生于 1978 年，哈尔滨道外人。

*   **履历**（影响造型的每一段都要体现在身上）：

    *   1996 年，18 岁，进市亚麻纺织厂当挡车工。三班倒，手指被纱线割出的细口子没断过。

    *   2001 年，23 岁，下岗潮。拿买断工龄的万把块钱出厂，出厂那天把工装叠得方方正正交了回去。

    *   2002 年，用买断钱在老道外盘下小门脸，"秀兰缝纫铺"。前店后宅，从此没离开过这条街。

    *   2009 年，丈夫病逝，一个人把铺子和女儿撑着。

*   **人物核心**：她的手艺是时代的遗物。全游戏她唯一不需要学习的就是"线"——她一辈子都在和线打交道，她早就看得见线。她唯一要学的是**放手**——注意：不是剪断。线永远不能被剪断，她能学会的只是**让线松着**：线还在，只是不再绷紧。

*   能力设定：她能看到与女儿之间的关联（即牵挂线），也能看到所有其他人的，并且能够对牵挂线施以有限的作用（例如，循着牵挂线发现另一端的关系，能够拨动牵挂线等等）。她从小见过各式各样的牵挂线，也见过彻底断裂的牵挂线（那通常是悲剧发生，例如，在她丈夫死去时，与她们母女关联着的牵挂线就消失了。）不过，她不会主动将这个能力说出去，因为知晓他人的关系和秘密，通常会带来悲剧（这里会有其他故事设定补充），在女儿第一次觉醒实体化牵挂线能力的时候，她下意识感到恐惧，在那之后便向女儿施加心理暗示，希望女儿忘记这项能力，作为平凡人度过即可。

*   在游戏发生的时间段中，由于孩子将要离开，母亲内心的情感太过强烈却难以向孩子表达、无法诉说，因此母亲实体化的能力被强化，将她内心“希望拴住孩子”的潜意识外化，导致牵挂线在母女二人之间获得了物理实体（外人看不见）。

### 造型（48 岁 · 主线）

*   身高偏矮，体态微驼（常年伏案），肩膀厚实。

*   头发在脑后挽一个低发髻，碎发多，鬓角有白。或者设计为短发亦可。

*   深色系旧毛衣 + **围裙**：深色棉布围裙，大口袋，口袋边缘磨得发白，上面有别针、顶针、一段粉笔线。围裙上有**补丁**——她自己补的，针脚细密。

*   手：指节粗大，指尖有针茧，右手食指侧面有一道旧疤（纱线割的）。她的焦虑、爱、愧疚，可以通过手的姿势表达。

*   表情基调：平稳、内敛。

### 造型（33 岁 · 闪回）——按 2009 年的潮流，要时髦

**她是"会打扮的妈妈"。** 送女儿上学的路上，会被别的家长回头看。下岗没有磨掉她的体面，开铺子挣了钱，她舍得给自己买衣服。

*   同一张脸，皮肤紧致，气色好。

*   发型：**当年流行的烫染**——栗棕色中长大卷（离子烫/陶瓷烫质感），别一只水钻发卡。

*   穿搭（上学路外出装）：**修身小西装外套 + 及膝裙 + 坡跟单鞋**，或高领薄毛衣配长风衣；手腕一只小巧的手表。配色可以暖亮（驼色、酒红、米白）。

*   围裙只在铺子里系，出门即摘——**这条街她既是裁缝余秀兰，也是"念念她妈"**，出门的样子是她自己选的。

*   耳饰：一对小珍珠耳钉。

*   动作幅度更大，走路带风。

### 动作库（游戏玩法需求）

*   行走（慢而稳，重心低）

*   推动重物（身体前倾，用上全身重量）

*   锚定（E）：双脚站定，微微下蹲，一只手扶住身边固定物（路灯/栏杆/桌沿），**整个人"沉"下去**

*   攀线：双手攀线，一寸一寸横向移动。

*   待机小动作：摸围裙口袋、用拇指捻线头、拍打衣服上不存在的线头

## 4.2 余念（女儿）

### 基本信息

*   23 岁，刚工作（设计师/美工类工作）。

*   离家不是去远方，是**同城搬出去**——地铁换乘两三回的距离。这个距离本身就是主题：她没有走远，她只是想有一段"自己的距离"。

*   **人物核心**：敏感、注重个人秩序。秩序是她的盔甲，母亲的照料对她来说是"入侵"。嘴上拒绝牵挂，手上一直把玩手腕的串珠

*   能力设定：女儿继承了母亲能够通过潜意识外化、影响牵挂线的能力，心灵细腻而敏感。七岁时，她和母亲出门，意外落入深坑，在母亲的高度紧张情绪下，第一次实体化了牵挂线，成功脱险。不过，在那之后，由于母亲反复向她暗示，她便忘记了这件事，长大后认为那不过是儿时的幻想。

### 造型（23 岁 · 主线）——前卫、小众、亚文化感（美术老师可以按照自己的理解来）

**她的审美宣言是：拒绝主流，也拒绝妈妈的主流。** 她是这条老街走出去的人里，穿得最"不像这条街"的那个——但不是潮牌堆砌，是有自己体系的亚文化穿搭。

*   瘦高。发型：**黑色长发带一处挑染**（暗红或亚麻灰一绺），或利落的鲻鱼头/层次感短发【二选一，待定】；额发有点乱，是自己剪的。

*   耳饰：**一排耳骨钉 + 一只不对称耳坠**（一边长一边没有）。

*   穿搭关键词：oversize 乐队T恤/古着衬衫、**自己改制的牛仔外套**（拼布、手绘涂鸦、拆掉又重缝的袖口——她的改造手艺来自母亲，她不会承认）、阔腿工装裤、厚底鞋。帆布包上别满徽章、挂着手绘挂件。

*   身上至少有一处**自己的手工改造痕迹**——这是她人物的核心视觉矛盾：嘴上嫌弃缝纫铺，手上的针脚比谁都好。

*   **手腕串珠（核心道具）**：木珠 + 缝纫线串的手链，混在她一堆金属/编织手绳中间，是最旧、最不起眼的一条，但她从没摘过。来历：小学时母亲用剩下的木珠和缝纫线给她串的，"说好戴到线断"。线一直没断。

*   表情基调：比母亲外露，烦躁、心虚、愧疚都在脸上写着，但**说完硬话会移开视线**。

### 造型（7 岁 · 闪回）

*   矮、圆、快。双马尾。

*   小学校服 + 明显大了一号的外套（母亲改的，袖口有翻折缝边）。

*   书包上挂着小挂件，跑起来晃。

*   **串珠已经在手腕上**（那时是新的、木珠还有光泽）。

### 动作库

*   23 岁：行走（快）、跳跃（轻盈、距离远）、钻低矮处（侧身收肩）、搬箱子（吃力，咬牙）

*   7 岁：走路蹦跳、原地转圈、被线拉住时整个人被"拽得一顿"、踩空坠落、悬挂后攀线爬回（小手一把一把倒）

*   共通待机小动作：捻手腕的串珠（**这是全书最重要的待机动画，心虚或不安时捻得快**）

## 4.3 黄伞（按角色资产规格制作）

*   女儿小学时的伞，明黄色，上面有猫咪图案，伞面有轻微的旧。

*   功能弧：小学时母亲送的（"下雨天隔着一条街都看得见"）→ 第一章女儿拒收 → 第三章线寄存在伞上 → **第四章出现在女儿出租屋门后**。

*   黄伞是两个时代里**唯一和线同等级别的高饱和色**。

## 4.4 次要人物

*   **不设计父亲形象。** 父亲只以痕迹存在：缝纫铺里一张扣着的相框、围裙的一个旧口袋。不做遗像特写、不做闪回出场。

*   可能出现的路人（早点摊老板、校门口家长、骑车人）：剪影级精度即可

# 五、场景资产

## 5.1 序章 + 第一章：缝纫铺与女儿的房间（室内 · 冷灰蓝）

**空间**：老道外门脸房，前店后宅，女儿房间在二楼。

| 资产     | 说明                                                                              |
| ------ | ------------------------------------------------------------------------------- |
| 缝纫铺店面  | 玻璃柜台（里面码着线轴墙——**整面墙的彩色线轴是全店唯一的色彩密集区**）、老式缝纫机（蝴蝶牌样式，黑色机身金色花纹）、熨衣板、挂着的待取衣物（罩着塑料布） |
| 招牌     | "秀兰缝纫铺"。【待定】建议用手写美术字风格，不要做打印体                                                   |
| 女儿房间   | 半打包状态：纸箱（胶带封了一半）、行李箱敞开、书桌上台历圈着日期、衣柜顶有相框、床底（低矮空间，玩法需要）                           |
| 五个互动物件 | 纸箱、行李箱、书桌、床底的耳机、衣柜顶的相框——每个物件需要"调查前后"的状态差分                                       |
| 门口     | 门垫、伞架（伞架空着——伞在母亲手里）、楼道暖声控灯                                                      |

**氛围**：清晨，阴天，冷光从窗进来。**全场景唯一红色来源：线轴墙 + 牵挂线。**

## 5.2 第二章：上学路（街景 · 2009 · 暖金）

**一条直线街道，约 5 个屏幕长度，从家门口到小学校门。**

| 区段         | 资产                                                         |
| ---------- | ---------------------------------------------------------- |
| A 家门口段     | 缝纫铺门脸、早点摊（蒸汽）、停放的自行车群（其中一辆倒地——玩法障碍）                        |
| B 街中段      | 大水洼（玩法）、横穿街道的晾衣绳、蜂窝煤炉、坐在门口择菜的老人（背景剪影）                      |
| C 快递柜/围墙段  | 老式小区围墙，底部一处破损缺口（高仅容小孩钻过）、铁门与踏板机关（美术上做成"门卫室配重闸门"，玩法机关需符合时代） |
| D 施工段      | 路面临时木板便道（会断）、沙堆、警示灯（暖黄闪烁）                                  |
| E 路灯段 + 街角 | **铁艺路灯（绿色灯座玻璃灯罩，关键道具）**、邮筒、街角高台阶、远处可见小学校门与铁栅栏              |

**氛围**：初秋早晨，斜射的金色阳光，蒸汽和炊烟，所有影子很长。7 岁女儿的影子小小的，母亲的影子把她罩住。

## 5.3 第三章：搬家楼道与老楼（室内+天台 · 冷灰蓝）

| 场景   | 资产                                                       |

## 6.3 线相关动画

*   线状态机全套过渡（松弛↔张力↔极限→锚定），过渡时长 0.2–0.4s，不允许跳变

*   摆荡物理（悬链线 + 钟摆）由程序驱动，美术提供线的**分段贴图与末端毛边**

*   极限状态的震动：高频小幅，不做大幅度甩动（真实棉线崩紧是"嗡"不是"甩"）

## 6.4 定点第一人称过场（少量）

*   机制：玩家可在**反光物前**（橱窗、水洼、灯箱广告）切换第一人称，看到"对方眼中/眼中的自己"。

*   美术需求：3–4 张第一人称静态插画（带轻微呼吸感动态）。风格可比游戏主体更细腻，允许画得"像插画"。

*   用途：每章一次，纯叙事，无玩法。

# 七、美术风格规格

## 7.1 风格定位

**双层风格：玩法层像素厚涂，演出层手绘动画。**

**玩法层（探索、解谜、平台动作）**：参照《风来之国》（Eastward）的技术路线：

*   角色与场景为像素基底（低分辨率绘制，放大呈现），但**光影、光晕、粒子用高精度图层叠加**，形成"像素皮肤 + 现代光影"的质感。

*   场景分层：远景剪影层 / 中景建筑层 / 前景遮挡层（晾衣绳、窗框、树枝），横移时有视差。

**演出层（对话、特写、开场、第一人称过场、关键剧情定格）**：参照《三伏》的手绘动画风格：

*   **清晰的手绘线稿 + 胶片感平涂上色**，人物半身/特写立绘，非像素。

*   标志性构图：**纯色背景 + 人物居中半身像**，情绪靠表情细节和背景色承载——第三章"视线构图"等关键剧情直接使用这种"证件照式"正面构图（两人背对背/面对面的半身像，线在两人掌心之间横贯画面）。

*   演出层允许出现"取景框"式的画面框（拍照感、旧电视圆角框），用于记忆、闪回与第一人称段落。

*   对白呈现：画面底部压字幕条，说话人名用颜色区分（母亲暖灰、女儿冷灰）。

两层分工：**玩的时候是像素的，动情的时候是手绘的。** 切换时不做过渡解释，玩家自然接受（《三伏》《烟火》已验证这种语言对中式叙事玩家有效）。

## 7.2 精度与规格（建议值，引擎确定后可调）

| 项       | 规格                                      |
| ------- | --------------------------------------- |
| 游戏逻辑分辨率 | 480×270（16:9），整数倍放大                     |
| 角色高度    | 女儿（23）约 38px；母亲约 48px（宽于女儿）；女儿（7）约 26px |
| 场景 tile | 16×16                                   |
| 线       | 基础宽度 2px，张力状态 2px+发光层，近景演出时单独绘制高清版本     |
| 帧率      | 角色动画 8–12fps（手绘感）；线物理 60fps 程序驱动        |
| 演出层立绘   | 手绘高清（非像素），纯色背景半身像，输出分辨率 ≥ 1920×1080 可用  |

## 7.3 调色板（基准值，允许微调 ±10%）

**现代（冷）**：主灰蓝 #3B4252 / #4C566A，地面 #2E3440，人物压暗；暖色只允许：线红 #C0392B、伞黄 #E8B93E、声控灯暖 #D8A24A（局部）。
**闪回（暖）**：主金 #D8A24A / #C97B2D，天空 #E8C98F，阴影偏紫 #5A4A6A；冷色只允许：水洼反光、女儿校服的一点点蓝。
**霜断**：全线去饱和，L 值整体 -20%，声音配合闷掉。

## 7.4 道具哲学

> **道具选得准，比画得细重要。**

每件道具必须"在中国家庭里真实出现过"：蜂窝煤炉、格子桌布、金属防盗门、红蓝白编织袋、塑料门帘、写着"拆"字又被涂掉的墙。画之前先问：这东西 2009 年的哈尔滨老道外有没有？

# 十、一页速查（贴墙版）

*   **基调**：克制的、日常的、最后决堤的。画日子，不画惨。

*   **城市**：哈尔滨老道外（不明说）。满城都是线：电线、晾衣绳、冰溜子。

*   **双时代**：2009 暖金 / 2020s 冷灰蓝。线在两时代颜色一致。

*   **线**：棉线红，永远自发光，冷画面里唯一热源。**从两人手心长出——像血管，从手腕皮肤下延伸出来。** 四状态：松弛/张力/极限/锚定。无数值系统。霜断\=消失，不做碎裂。**线永远不能断，只能松——放手不是剪断。**

*   **母亲**：48 岁，纺织厂下岗→缝纫铺。手比嘴忙。全游戏只哭一次。33 岁闪回版按 2009 年潮流设计：**要时髦**，是"会打扮的妈妈"。

*   **女儿**：23 岁，同城搬家。亚文化感穿搭，身上有手工改造痕迹。嘴上拒绝，手上捻串珠。

*   **风格双层**：玩法层像素厚涂（风来之国），演出层手绘动画（三伏——纯色背景半身像+字幕条）。

*   **黄伞**：两时代里唯一与线同级的高饱和色。结局门后那张图是全书最重要的一张。

*   **规格**：480×270 像素厚涂 + 光影分层；角色 8–12fps；线 60fps 程序驱动。

*   **第一参考**：《完美的一天》（转译方法）、《风来之国》（技术质感）、《漫长的季节》（东北调色）、《钢的琴》（横移分镜）、Unravel（线）。

*   **铁律**：线永远是画面里最重要的东西。
