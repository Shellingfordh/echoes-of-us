# 角色设定｜Characters

## 1. 角色设计原则

《不断线》的角色不是传统意义上的“功能 NPC”。

角色行为必须同时服务于：

1. 建立关系；
2. 推进玩家体验；
3. 传递情绪；
4. 支撑牵挂线的叙事含义。

角色台词不应把玩家已经能看到的东西全部解释出来。

例如，不建议：

> “你看，我们之间出现了一根蓝色的线，这代表我们的关系。”

应该让角色先表现出自然反应，再由玩家通过机制理解。

# 2. Mother｜母亲

## 基础信息

| 项目 | 内容 |
|---|---|
| ID | C001 |
| 年龄 | 40s |
| 身份 | 女儿的母亲 |
| 当前状态 | 仍然习惯照顾成年女儿 |
| 核心性格 | 温柔、谨慎、克制 |
| 核心矛盾 | 想保护女儿，但知道必须让她独立 |
| 叙事功能 | 关系的另一端、情绪来源 |
| 视觉关键词 | 温暖、柔和、略显疲惫 |

## 人物核心

母亲不是“控制女儿的人”。

她只是没有学会如何从“照顾者”变成“旁观者”。

她会自然地说：

> “带伞了吗？”

但她真正想说的是：

> “我还能够照顾你吗？”

她会提醒女儿慢一点，但不会强迫女儿停下来。

## 外观方向

成年母亲：

- 40 岁左右；
- 身体姿态略微前倾；
- 动作不快；
- 面部表情克制；
- 服装偏生活化；
- 色彩以暖米色、棕色、低饱和红色为主；
- 不使用明显的“慈祥老人”符号；
- 保持普通城市母亲的可信度。

动作重点：

- 整理衣服；
- 拿伞；
- 看向女儿；
- 下意识跟随；
- 女儿走远时停下来。

## 性格关键词

正向：

- 温柔；
- 细心；
- 可靠；
- 有责任感；
- 克制。

负向：

- 过度担心；
- 不善于表达；
- 偶尔唠叨；
- 不容易接受变化。

## 情绪曲线

### 开场

状态：

> 自然、放松。

她认为女儿仍然在自己的生活范围内。

### 第一次分离

状态：

> 下意识担心。

但她不会立刻追上去。

### 牵挂线张力

状态：

> 想靠近，但开始意识到女儿需要空间。

### 黄色雨伞

状态：

> 记忆被触发。

台词减少，更多使用沉默和环境声音。

### 结尾

状态：

> 接受。

她不再追。

这不是放弃，而是信任。

## 关键行为

| 行为 | 叙事意义 |
|---|---|
| 看向女儿 | 关注 |
| 跟随女儿 | 保护 |
| 停下 | 学习放手 |
| 不追上去 | 尊重女儿 |
| 看向牵挂线 | 意识到关系仍然存在 |

## 关键台词方向

### 日常

> “慢一点。”

> “东西带齐了吗？”

### 第一次分离

> “你别走太远。”

### 张力

> “没事，我就在这儿。”

### 记忆

不建议大量对白。

可以只保留：

> “伞往你这边一点。”

### 结尾

> “去吧。”

这是全 Demo 中非常重要的一句。

应该避免煽情表演。

# 3. Daughter｜女儿

## 基础信息

| 项目 | 内容 |
|---|---|
| ID | C002 |
| 年龄 | 20s |
| 身份 | 成年女儿、玩家角色 |
| 核心性格 | 独立、好奇、略叛逆 |
| 核心矛盾 | 想离开，但不想伤害母亲 |
| 叙事功能 | 玩家视角、关系变化的主动方 |
| 视觉关键词 | 轻盈、年轻、行动性强 |

## 人物核心

女儿并不讨厌母亲。

她甚至很依赖母亲。

但她开始意识到：

> 如果自己永远停在原地，就永远无法成为真正独立的人。

因此她的“走远”必须被表现为成长，而不是逃跑。

## 外观方向

- 20 岁左右；
- 动作比母亲更快；
- 站姿更直；
- 服装简单、现代；
- 色彩略偏冷；
- 与母亲形成视觉上的暖/冷对比。

## 性格关键词

- 好奇；
- 独立；
- 温柔；
- 有一点不耐烦；
- 会内疚；
- 有行动力。

## 情绪曲线

### 开场

> 自然、轻松。

### 母亲提醒

> 略微不耐烦。

### 第一次发现牵挂线

> 好奇。

### 牵挂线产生张力

> 从好奇转为不安。

### 记忆

> 怀念。

### 结尾

> 理解母亲，也接受自己的离开。

## 玩家角色原则

女儿是玩家角色，因此不要让她说出过多“正确答案”。

玩家应该通过：

- 移动；
- 靠近；
- 远离；
- 连接；
- 观察；
- 触发记忆；

自己理解女儿的情绪变化。

# 4. Child Daughter｜童年女儿

| 项目 | 内容 |
|---|---|
| ID | C003 |
| 年龄 | 7～10 岁 |
| 功能 | 记忆中的女儿 |
| 性格 | 活泼、信任母亲 |
| 视觉关键词 | 明亮、轻盈、黄色 |

童年女儿不需要复杂对白。

她的核心作用是让成年女儿看到：

> “小时候的我根本不知道妈妈为什么总是这样保护我。”

---

# 5. 角色关系

```text
Mother
   │
   │ 保护 / 担心
   │
   ▼
Daughter
   │
   │ 成长 / 离开
   ▼
独立生活
```

牵挂线连接的不是“母亲和女儿的身体”，而是：

> 母亲对女儿的牵挂 + 女儿对母亲的情感回应。

因此结尾不能把线处理成普通绳子断裂。

---

# 6. 角色在关卡中的目标

### Mother

主要目标：

> 让玩家始终意识到“有人在乎你”。

### Daughter

主要目标：

> 让玩家亲自经历“走远”。

### Child Daughter

主要目标：

> 让玩家看到关系的过去。

---

# 7. 角色禁区

不要：

- 把母亲写成反派；
- 把女儿写成不孝；
- 用大段独白解释人物；
- 用哭泣代替情绪设计；
- 用明确旁白告诉玩家“母爱很伟大”；
- 让角色为了推进剧情做出不符合性格的行为。

核心原则：

> **少解释，多表现。**
