# 一、文档说明

本文件是关卡、技术、美术、演出与配音共同使用的对白接口文档。所有对白使用固定 ID。技术与关卡只通过 ID 调用，不在其他文档或场景中另写正式台词。后续修改措辞时，只修改本表中对应 ID 的“台词”字段，不改动 ID。

固定字段为：ID、触发条件、角色、台词、情绪、是否阻塞流程。

“是否阻塞流程”说明：

*   **是**：触发后暂时收束玩家操作，待该条对白或无对白演出结束后恢复；

*   **否**：对白可在探索、移动或机制反馈中播放，不要求玩家停下。

## Scene 11｜沉默、上车与列车离开

**无母女对白。**

*   两个人停止回应后，线自身褪灰，世界颜色保持正常。

*   余念过检票、上车、坐下；不说“妈我走了”。

*   余秀兰不再重复“到了打电话”。

*   可以保留正常车站广播，但只承担空间真实性。

## Scene 12｜现在时余秀兰视角与最终分歧

**无人物对白。**

玩家需要自行看见：李婶、老主顾、高中姑娘、邻居等具体人物的线；父亲的残端；以及向南延伸、很长却已经不绷紧的女儿线。

禁止添加：

*   “原来线可以这么长。”

*   “原来我也被这么多人牵挂。”

*   “我该为自己活一次了。”

*   “你长大了。”

最终“往前 / 往回”通过空间行动完成，不出现菜单文字选项。

# 八、没有对白的关键段落

| 段落            | 禁止原因                   |
| ------------- | ---------------------- |
| 序章全部          | 父亲事故与母亲动机由镜头、声音、两只手建立  |
| 第一章牵挂线最初显形的数秒 | 玩家先看见、先操作，再让余念开口       |
| 第二章踩空后的最危险瞬间  | 先让承重动作成立，再进入 D024      |
| 第三章黄伞入箱       | 必须像母亲的本能动作，不能说“偷偷给你带上” |
| 第四章线褪灰        | “沉默”本身必须成立             |
| 第四章余念上车至列车离开  | 除公共广播外不补母女对白           |
| 第四章母亲关系网络显形   | 视觉负责解释母亲的一生            |
| 最终空间分歧        | 不出现文字选项和总结式独白          |
| 共同黄伞尾声        | 不重复主题，不加独白             |
