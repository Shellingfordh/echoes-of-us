# 剧情总纲｜《不断线》Demo

## 1. 项目定位

《不断线》是一款以“关系”为核心驱动力的叙事解谜游戏 Demo。

玩家扮演成年后的女儿，在一次与母亲同行的日常经历中，逐渐看见人与人之间原本不可见的“牵挂线”。这条线并不是传统意义上的绳索，而是关系、记忆、依赖与情感的可视化表达。

Demo 不追求复杂世界观和大量关卡，而是用 3～5 分钟完成一次完整的情绪闭环：

> 熟悉 → 发现 → 学习 → 使用 → 回忆 → 理解 → 放手 → 不断线

## 2. 核心主题

### 2.1 表层主题

母女之间的距离。

### 2.2 深层主题

“放手”并不意味着关系消失。

母亲希望女儿安全，希望她留在自己身边；女儿则希望拥有自己的生活。两个人真正的冲突不是“爱不爱”，而是“爱是否必须以靠近为形式”。

游戏最终希望玩家理解：

> 人可以离开彼此，但关系不一定因此断裂。

## 3. 核心机制与叙事的关系

游戏中的“牵挂线”必须同时承担玩法和叙事两个职责。

玩法层面：

- 表示两个对象之间存在关系；
- 距离变化会改变线的状态；
- 玩家可以利用连接解决环境谜题；
- 某些连接可以触发记忆或改变场景状态。

叙事层面：

- 让玩家第一次“看见”母女关系；
- 将抽象的牵挂变成可操作对象；
- 在结尾让玩家意识到，线的意义不是束缚，而是连接。

因此，牵挂线不能被设计成普通的“魔法绳子”。玩家应该逐渐理解它为什么存在。

## 4. 故事背景

故事发生在一个普通的家庭环境中。

成年女儿正在逐渐离开熟悉的生活。母亲仍然习惯性地照顾她、提醒她、担心她。

两个人没有发生激烈争吵，也没有明确的“决裂事件”。真正的情绪来自日常生活中那些很小的瞬间：

- 母亲反复确认女儿有没有带伞；
- 女儿嫌母亲总是担心；
- 母亲下意识跟在女儿身后；
- 女儿开始主动拉开距离；
- 两个人都没有真正说出口自己的害怕。

黄色雨伞是两个人共同记忆的重要意象。

小时候下雨时，母亲总会把伞往女儿这一侧倾斜。多年以后，同一把黄色雨伞成为记忆的入口。

## 5. 主要角色

### Mother｜母亲

40 岁左右。

她不是一个“控制欲很强的反派母亲”，而是一个很普通、很爱孩子、但不擅长表达自己恐惧的人。

她的核心矛盾：

> 她知道女儿应该长大，却不知道自己应该怎样停止保护她。

她说“注意安全”，真正想表达的是：

> “我不知道没有我的保护以后，你会不会受伤。”

### Daughter｜女儿

20 岁左右。

她好奇、独立、略带叛逆，但并不讨厌母亲。

她真正想要的不是逃离母亲，而是证明自己能够独立生活。

她的核心矛盾：

> 她需要离开，但又害怕自己的离开会伤害母亲。

## 6. 故事流程

### 第一段｜同行

母女处于同一空间。

玩家首先看到两个人自然地移动、停留和交谈。

此时不要立即解释牵挂线。

目标是建立：

> “她们原本就是一起生活的人。”

玩家应该先感受到关系，再看到机制。

### 第二段｜第一次分离

女儿开始主动走远。

当距离超过自然范围，玩家第一次看到牵挂线。

母亲没有立即阻止女儿。

线开始产生张力。

玩家第一次理解：

> 距离越远，关系的“张力”越明显。

### 第三段｜学习

玩家主动尝试改变距离。

通过几次简单反馈理解：

- 线会跟随；
- 线有安全范围；
- 线进入张力状态；
- 某些物体也可以与线形成关系。

这里不需要复杂教程文本，应尽量让视觉反馈承担教学。

### 第四段｜核心谜题

玩家需要利用牵挂线连接环境中的几个对象。

谜题不是为了炫耀机制，而是让玩家产生一个重要认知：

> 关系本身可以成为解决问题的方法。

环境中的物体应该与母女记忆存在合理关联，例如：

- 相框；
- 雨伞；
- 门；
- 灯；
- 椅子；
- 旧照片。

### 第五段｜黄色雨伞

玩家接触黄色雨伞。

环境逐渐发生变化。

现实空间和记忆空间短暂重叠。

声音、灯光、色彩发生改变。

玩家进入童年记忆。

### 第六段｜记忆

记忆不是完整回放一段故事，而是一个很短的情绪片段。

雨天。

母亲撑着黄色雨伞。

小女孩站在母亲身边。

母亲把伞向女儿一侧倾斜。

女儿当时没有意识到这是保护。

成年后的女儿终于理解：

> 那些看似普通的动作，其实就是母亲表达爱的方式。

### 第七段｜结尾

回到现实。

女儿继续向前走。

母亲没有追上来。

两个人之间的距离变远。

牵挂线仍然存在，但不再剧烈拉扯。

最终画面不是“线断了”，而是：

> 线变得更细、更安静，但仍然连接着两个人。

## 7. 情绪曲线

| 阶段 | 玩家情绪 | 叙事目的 |
|---|---|---|
| 同行 | 温暖、熟悉 | 建立关系 |
| 发现牵挂线 | 好奇 | 建立核心意象 |
| 第一次张力 | 紧张 | 建立距离与关系的联系 |
| 解谜 | 专注、理解 | 让玩家主动使用关系 |
| 黄色雨伞 | 怀旧 | 打开过去 |
| 童年记忆 | 柔软、心酸 | 揭示母亲的情感 |
| 回到现实 | 安静 | 让情绪沉淀 |
| 结尾 | 释然 | 完成主题 |

## 8. 核心意象

### 牵挂线

代表：

- 牵挂；
- 依赖；
- 记忆；
- 情感连接；
- 无法完全解释的关系。

### 黄色雨伞

代表：

- 母亲的保护；
- 童年；
- 雨天记忆；
- 过去与现在的连接。

### 距离

距离不是简单的空间参数。

它应该成为情绪参数：

> 越近，不代表关系越好；越远，也不代表关系消失。

## 9. Demo 叙事边界

本 Demo 不展开：

- 父亲或其他家庭成员的完整故事；
- 母女关系的长期历史；
- 复杂社会背景；
- 超自然世界观解释；
- 大量支线；
- 多结局。

所有内容必须服务于一个核心问题：

> “当女儿走远以后，她和母亲之间的关系还在吗？”

## 10. 完成标准

玩家完成 Demo 后，应该能够不依赖额外解释说出类似：

> “原来那根线就是她们之间的关系。”

如果玩家只觉得：

> “这是一个可以拉东西的绳子。”

则叙事和玩法之间的结合还没有成立。
