# Story (示例)

标题：不断线（Demo）

概述：一段母女关系的短篇体验，通过牵挂线揭示记忆与情感的连接。Demo 时长目标 3～5 分钟，包含引导、核心谜题、记忆场景与结局。

节奏拆分：
1. 引导（0:00-0:45）：介绍牵挂线与角色关系。
2. 学习（0:45-1:30）：玩家学习牵挂线交互。
3. 核心谜题（1:30-3:00）：利用牵挂线解锁记忆节点。
4. 记忆场景（3:00-4:15）：短演出，情感高点。
5. 结局（4:15-4:30）：关系理解与离别。

目标体验：让玩家在解谜与视觉叙事中理解母女的牵挂与成长。
