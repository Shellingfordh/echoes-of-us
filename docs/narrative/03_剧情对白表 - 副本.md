# 一、文档说明

本文件是关卡、技术、美术、演出与配音共同使用的对白接口文档。

所有对白使用固定 ID。技术与关卡只通过 ID 调用，不在其他文档或场景中另写正式台词。后续修改措辞时，只修改本表中对应 ID 的“台词”字段，不改动 ID。

固定字段为：

| ID | 触发条件 | 角色 | 台词 | 情绪 | 是否阻塞流程 |
| -- | ---- | -- | -- | -- | ------ |

“是否阻塞流程”说明：

*   **是**：触发后暂时收束玩家操作，待该条对白或无对白演出结束后恢复；

*   **否**：对白可在探索、移动或机制反馈中播放，不要求玩家停下。

# 二、对白设计原则

1.  对白不直接解释牵挂线的世界规则。张力、承重、锚定、沉默与松弛，优先通过玩家经历和视听反馈被理解。

2.  余念习惯用事实、路线、价格和生活安排表达边界；她很少直接说“我难过”或“我舍不得”。

3.  余秀兰习惯用天气、吃饭、药品和收拾东西表达关心；她很少直接说“我不想让你走”。

4.  七岁的余念直接、活泼，面对危险时会害怕，但恢复得快。

5.  第三章的对白服务协作节奏，不把“互相支撑”说成口号。

6.  第四章保持克制。再次冲突必须真实存在，但不以一段解释一切的和解对白收尾。

7.  序章“红线”全程无对白，不占用新的对白 ID。缝纫机停下、母亲抬头、母女掌心红色脉络与标题出现均由演出承担。

# 八、对白管理与验收原则

## 1. ID 稳定性

*   D001–D040 均为固定 ID；

*   每个 ID 在本文件中只出现一次；

*   不因文字润色、配音调整或演出节奏改变而重排 ID；

*   若同一触发需要分句显示，应在该 ID 内处理，不新增临时编号；

*   如未来确需新增对白，从 D041 起顺序追加。

## 2. 叙事信息边界

对白可以帮助玩家确认角色感受，但不能替代以下玩法认知：

*   第一章：距离与意图冲突会让线产生张力，极限张力可以回拉并承重；

*   第二章：拉住有时意味着保护，支撑不等于替对方行动；

*   第三章：两个人可以轮流成为锚点，能力差异可以转化为合作；

*   第四章：线的沉默不是自由，放手也不是切断，稳定连接可以保持松弛。

## 3. 情绪曲线

| 章节  | 对白状态                    | 关系表达                |
| --- | ----------------------- | ------------------- |
| 第一章 | 生活化独白逐渐进入防御与误解          | “你在阻止我离开。”          |
| 第二章 | 短促、直接、以危险中的指令为主         | “我拉住你，是为了让你还能自己回来。” |
| 第三章 | 对白变成协作确认与交接             | “我们可以轮流托住彼此。”       |
| 第四章 | 冲突后大幅留白，最后只保留尊重边界的生活化表达 | “连接仍在，但我不再替你决定距离。”  |
