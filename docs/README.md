## 技术

`technical/`

负责：

- Godot 技术架构
- 开发规范
- 核心机制实现说明

剧情定义“为什么发生、发生什么” → 关卡定义“玩家怎么经历它” → 技术定义“怎么实现” → 美术定义“看起来是什么”

但这里有一个关键例外：

剧情可以直接向技术提出“需求”，但不应该直接规定技术实现。

例如剧情写：

女儿拿起黄色雨伞后进入童年记忆。

这是剧情需求。

关卡再把它翻译成：

玩家靠近雨伞 → 出现交互 → 点击后触发记忆场景 → Camera 转场 → 玩家控制权恢复。

技术看到的是这个。

剧情不要写：

“技术使用 SceneManager 切换 Scene，然后调用 xxx API。”

这会把职责搞乱。
