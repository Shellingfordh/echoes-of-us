# 美术圣经｜Art Bible

## 1. 项目视觉目标

《不断线》的视觉目标不是追求写实，而是让玩家感觉：

> 像一本会动的、带有真实生活痕迹的绘本。

关键词：

- 手绘；
- 水彩；
- 柔和；
- 安静；
- 留白；
- 轻微颗粒；
- 2.5D；
- 情绪化光影。

整体避免：

- 高饱和商业卡通；
- 过度日系萌化；
- 纯写实 3D；
- 复杂科幻 HUD；
- 过度发光特效。

---

# 2. 视觉结构

推荐采用：

```text
Background
↓
Midground
↓
Character
↓
Foreground
↓
Effects
↓
UI
```

通过多层景深制造 2.5D 视差。

---

# 3. 色彩系统

## 现实空间

现实空间：

> 暖米色 + 灰褐色 + 低饱和蓝。

目的：

> 让环境像真实生活，而不是童话世界。

## 记忆空间

记忆空间：

> 更柔和、更低对比度。

可以提高：

- 暖色；
- 雾化；
- 光晕；
- 空气感。

但不要直接变成高饱和“回忆滤镜”。

---

# 4. 角色视觉

## Mother

主色：

> 暖米色、棕色、低饱和红。

视觉感觉：

> 稳定、温暖。

## Daughter

主色：

> 灰蓝、浅绿、低饱和冷色。

视觉感觉：

> 年轻、行动性强。

## Child Daughter

可以加入：

> 黄色 / 明亮暖色。

让童年阶段与黄色雨伞形成视觉关联。

---

# 5. 牵挂线

牵挂线是全项目最重要的视觉资产之一。

## 普通状态

- 半透明；
- 柔和发光；
- 低存在感；
- 不遮挡角色。

## Tense 状态

- 线宽增加；
- 发光增强；
- 轻微抖动；
- 色彩更偏暖。

## Stable 状态

结尾使用：

> 细、柔和、稳定。

不要让结尾的线比前面的线更“强”。

---

# 6. 牵挂线状态

| 状态 | 视觉 | 音效 |
|---|---|---|
| Hidden | 不显示 | 无 |
| Reveal | 渐显 | 轻微提示 |
| Normal | 细线 | 低存在 |
| Tense | 变粗、轻抖 | 张力声 |
| Stable | 柔和细线 | 环境音为主 |
| Broken | Prototype 不使用 | 不使用 |

“Broken”可以保留为系统状态，但本 Demo 不使用真正断裂作为结局。

---

# 7. 镜头

默认：

> 2D/2.5D 横向或斜向视角。

镜头动作要慢。

允许：

- 微弱跟随；
- 缓慢推进；
- 轻微拉远；
- 记忆转场时的空间变化。

避免：

- 快速摇镜；
- 大幅旋转；
- FPS 式镜头晃动；
- 游戏直播式镜头。

---

# 8. 场景

## Home

核心关键词：

> 普通、生活化、熟悉。

需要：

- 沙发；
- 桌子；
- 窗户；
- 家庭照片；
- 黄色雨伞；
- 常用生活物件。

不应该像“剧情专用房间”。

## Memory

与现实空间保持相似布局。

关键变化来自：

- 光线；
- 天气；
- 色彩；
- 角色年龄；
- 声音。

这样玩家会意识到：

> 这是同一个地方，只是时间不同。

---

# 9. UI

UI 应该弱化。

原则：

> 能不用 UI，就不用 UI。

交互提示：

```text
E  调查
```

即可。

避免：

- 大型任务框；
- 大量数值；
- RPG 面板；
- 复杂血条；
- 复杂背包。

---

# 10. AI 生成规范

如果使用 AI 生成素材：

必须统一：

- 角色脸型；
- 服装；
- 发型；
- 色彩；
- 光照方向；
- 透视；
- 场景结构。

AI 输出只能作为素材生产工具。

正式进入游戏前必须：

1. 去除明显生成瑕疵；
2. 统一尺寸；
3. 统一透视；
4. 统一色彩；
5. 确认与已有素材风格一致。

---

# 11. 禁止事项

禁止：

- 每张图使用完全不同的画风；
- 随意修改角色服装；
- 未经确认新增角色；
- 牵挂线颜色每个场景随意改变；
- 使用明显现代 UI 元素破坏绘本感；
- 直接把 AI 原图放进正式 assets。

---

# 13. 导出规范

默认：

- PNG；
- 透明素材使用 Alpha；
- 最大边长 2048 px；
- UI 与小型 Sprite 可根据实际需求降低尺寸；
- 不允许无意义地提交 8K 大图；
- 文件名使用英文；
- 不使用空格和中文。

Sprite 如果需要特殊 Pivot、裁切或九宫格：

必须在资产说明中记录。

---

# 14. 美术验收

正式素材必须同时满足：

- 风格一致；
- 比例正确；
- 命名正确；
- 尺寸合理；
- Alpha 正常；
- 无明显 AI 瑕疵；
- 在 Godot 中导入后显示正常。
