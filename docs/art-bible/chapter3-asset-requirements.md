## 1. 本文如何判断“已有”与“缺失”

### 1.1 状态定义

| 标记 | 状态 | 含义 |
|---|---|---|
| ✅ | 已有并可用 | 已进入工程、用途正确、风格/尺寸/Alpha 合格，并具备可追溯来源与许可 |
| 🟢 | 已有可复用 | 工程内已有候选素材，第三章可复用，但仍需在实际场景中确认比例、调色或动画 |
| 🟡 | 有参考，未正式化 | 参考图存在，但未进入正式 `assets/`、未按第三章规格拆分或未完成授权记录 |
| 🟠 | 有占位，不可交付 | 当前白盒能显示，但素材是通用占位、程序色块或风格不符，正式版必须替换 |
| ❌ | 缺失 | 没有找到可承担该用途的候选素材 |
| ❓ | 需求待确认 | 最新正式设计与早期 HTML 原型/当前工程存在差异，确认玩法后才能定稿 |
| ⚙️ | 程序生成 | 不要求独立位图，但仍需要颜色、材质、动画和性能规范 |

### 1.2 “Done”的严格口径

一个素材只有同时满足以下条件，才能标记为“已完成”：

1. 通过美术负责人风格审核；
2. 文件命名、尺寸、透明通道、Pivot 和动画信息完整；
3. 来源、作者和使用许可可追溯；
4. 已导入 Godot，在目标关卡中按实际镜头检查；
5. 不遮挡角色、牵挂线、落脚点和交互反馈；
6. 已随工程提交，而不是只存在于个人下载目录。

因此，`/Users/allen/Downloads/3/` 中的图片在本文中只能记作“参考候选”，不能记作正式完成。

### 2.1 已发现的设计差异

最新 v1.0 关卡设计的主线是：

`楼道断梯互相锚定 → 仓库推重箱/女儿钻低洞/母亲接受支撑 → 天台三级接力/黄伞入箱`

早期 HTML 原型和当前 Godot 场景另外加入了多组踏板门、可断木板、箱压门和箱子垫脚。它们有玩法实现，但不是 v1.0 文档中的完整正式结构。

**美术处理原则：**

- v1.0 明确需要的环境、角色和剧情动作可以立即制作；
- 额外的门、踏板、可断木板先按“❓需求待确认”处理；
- 可先做一套模块化机关基件供原型使用，但不要为每一扇门制作不可复用的高成本成品；
- 尤其需要确认天台终点究竟是“普通出口铁门”“双人拉杆门”还是“双方站踏板开门”。

## 5. 全章统一素材需求

### 5.1 视觉方向

- 玩法视角：纯 2D 横版侧视，不使用第二章的 2.5D XYZ 运动；
- 基准构图：480×270，16:9；当前工程以 960×540 显示，相当于 2×整数放大；
- 世界比例：32 px = 1m（以 480×270 基准计算）；
- 画面气质：有真实生活痕迹的像素厚涂/手绘绘本，而非写实贴图拼贴；
- 现实时间色调：主灰蓝 `#3B4252` / `#4C566A`，地面 `#2E3440`；
- 受控暖色：牵挂线 `#C0392B`、黄伞 `#E8B93E`、声控灯 `#D8A24A`；
- 分层顺序：远景 → 中景建筑 → 可玩地形/道具 → 角色 → 前景遮挡 → 特效 → UI；
- 牵挂线必须始终比电线和墙缝更容易辨认，但不能像激光武器。

### 5.2 角色比例与导出

- 角色非 Q 版，约 1:6 头身；
- 余秀兰与余念站立碰撞高度约 1.66m/1.68m，即基准约 53–54px；
- 建议完整美术轮廓高度为基准 56–64px（运行时 112–128px），最终以实机可读性为准；
- 角色 Pivot：`center-bottom`，双脚中点必须与地面重合；
- 动画建议 8–12fps，牵挂线仍由程序按 60fps 更新；
- 每个动画必须记录单帧尺寸、帧数、FPS、Pivot、循环方式、碰撞切换点和事件帧；
- 左右朝向可镜像的动作需明确；耳饰、挑染、围裙口袋、串珠和手腕连线点不能因镜像产生逻辑错误。

### 5.3 场景模块与安全区

- 背景不要做成覆盖整关的一张超长图，应按可循环模块和视差层拆分；
- 关键落脚点左右至少保留 0.8m 无视觉障碍；
- A 段断梯净宽固定为 3.0m；
- B 段低洞净高固定为 1.05m，货架和管线不能改变净空读法；
- B 段重箱终点中心为 `(39.0, 1.0)`；
- C 段三级间隙均为 2.0m，不能靠美术延长平台导致普通跳跃跳关；
- 所有前景遮挡必须有淡出策略，不能长时间挡住人物、落脚点或牵挂线。

## 6. 角色与动画清单

### 6.1 余念（23 岁）

现状：🟠 仅有通用圆形人偶的两帧走路和一帧锚定，占位不能体现人物身份。

造型要求：瘦高、黑发带暗红或亚麻灰挑染，亚文化穿搭，改制牛仔外套/古着、工装裤或半裙、厚底鞋、不对称耳饰；手腕串珠必须可读。

| 动画/状态 | 状态 | 要求 |
|---|---|---|
| `idle` | ❌ | 轻微呼吸；不安时捻串珠；至少普通/紧张两个节奏 |
| `walk` | ❌ | 步幅比母亲大、节奏更快；8–10 帧循环 |
| `run` | ❌/可选 | 若关卡保留奔跑输入则需要；否则不制作独立循环 |
| `turn` / `stop` | ❌ | 0.2–0.5 秒缓冲，不可瞬间翻转 |
| `jump_start` / `air` / `fall` / `land` | ❌ | 跳跃轻盈；必须清楚区分上升和下落 |
| `anchor_enter` / `anchor_loop` / `anchor_exit` | ❌ | 双脚站稳、重心下沉；不是把线绑在环境物件上 |
| `tether_boost` / `tether_climb` | ❌ | 借线跃迁、双手沿线移动、被承重时的身体张力 |
| `crouch_enter` / `crouch_walk` / `crouch_exit` | ❌ | 仓库低洞专用；碰撞从站立切换到 0.74×0.88m；头顶不足时保持蹲行 |
| `push_fail` | ❌ | 女儿尝试推动重箱但失败；反馈克制，不做滑稽表演 |
| `brace_pull_mother` | ❌ | 女儿成为稳定端承受母亲重量，是第三章关键动作 |
| `reach_hand` | ❌ | 向母亲伸手，动作要能与 D060 同步 |
| `fall_recover` | ❌ | 失败后由线短暂承住并回安全点，不做死亡演出 |
| `look_mother` / `relieved` | ❌ | 用于责任交换后的短暂停顿和章节结束 |
