## 六要素方法论

每个流程节点必须回答：
1. 玩家在哪里
2. 玩家看到什么
3. 玩家做什么
4. 什么条件触发
5. 触发之后发生什么
6. 玩家如何知道自己成功了

- 牵挂线状态可视化不足 → 四态（Hidden/Tense/Adjustable/Extending）映射到章节弧线
