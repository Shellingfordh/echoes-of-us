# 当前可玩实现索引

> 状态：当前执行版本  
> 剧情依据：`docs/narrative/04_剧情需求 - 副本.md`  
> 运行工程：`game/`

本文件用于锁定当前 Godot 原型与剧情需求的对应关系。目录中仍保留的“路人失物”“向外跑”“无限延伸”等文档属于历史方案，不再指导当前制作。

## 当前流程

| 段落 | 可玩内容 | 核心牵挂线状态 |
| --- | --- | --- |
| 序章 | 固定视角观看旧城缝纫铺；普通红线穿过门槛、楼梯，连接到楼上熟睡女儿的掌心 | 独立的红色生活线索 |
| 第一幕 | 调查搬家物件、收集记忆、母女冲突、显线、强制回弹、短暂承重与水平摆动、触碰黄伞 | Hidden → Tense |
| 第二幕 | 年轻母亲视角、自行车、水坑松线、儿童独行、路灯锚定、坠落悬挂、玩家主动沿线爬回、第一次放手 | Adjustable ↔ Tense |
| 第三幕 | 成年母女轮流锚定，利用体型和位置差异完成楼道、仓库与天台合作 | Adjustable |
| 第四幕 | 新住处搬箱、母亲再次越界、关系沉默、女儿独处、松弛连接重现 | Adjustable → Silent → Stable |
| 尾声 | 女儿独自在新家；旧黄伞留在门后，伞柄旁只保留一小段松弛红线 | Stable（以短线意象保留） |

## 剧情需求覆盖

| 需求 | 当前实现证据 |
| --- | --- |
| SR-001 序章红线 | `FullDemoWorld.Layout.PROLOGUE` 的两阶段无对白演出 |
| SR-002 固定观察与信息差 | 序章固定观察；第一幕成年女儿、第二幕年轻母亲的角色视角切换 |
| SR-003 黄色旧雨伞 | 第一幕冲突与记忆入口、第三幕主动锚定、尾声门后保留 |
| SR-004 第一次显线 | 距离达到阈值后从 Hidden 进入 Tense |
| SR-005 张力与强制回弹 | 距离增大降低移动能力，并触发第一次强制回弹 |
| SR-006 第一次承重与摆动 | 第一幕回弹时角色离地，玩家用左右输入完成短暂摆动 |
| SR-007 母亲视角与过去 | 第二幕控制年轻母亲，线从开场即为可见和可调节 |
| SR-008 保护与适度放松 | 水坑段通过靠近女儿把 Tense 恢复为 Adjustable |
| SR-009 坠落与沿线返回 | 小女儿坠入断口、被线悬挂，并由玩家持续向上输入爬回 |
| SR-010 第一次放手与锚定 | 路灯锚点后母亲留在原处，小女儿独自完成路线并告别 |
| SR-011 成年母女双角色支撑 | 第三幕楼道和天台要求双方交替锚定、交替通过 |
| SR-012 母女能力差异 | 仓库由母亲推重箱、女儿钻窄道，从另一侧打开路线 |
| SR-013 再次冲突与边界复发 | 新住处使用 D034–D036 完成再次越界与边界冲突 |
| SR-014 牵挂线的沉默 | 冲突后进入 Silent：冷色、冻结、近乎不可见且没有拉力 |
| SR-015 松弛重现 | D038–D039 后进入 Stable：暖色、下垂、无振动和回拉 |
| SR-016 黄伞尾声 | 无对白新家尾声，门后黄伞与一小段松弛红线同框 |

## 运行与验证

```bash
godot --path game
godot --headless --path game --script res://scripts/tests/smoke_test.gd
```

自动化流程会从序章一直推进到尾声，并验证暂停、静音、减少动态效果、`D001–D040` 对白目录、牵挂线状态转换和关键剧情检查点。
