# 交互规格｜Interaction Sheet（基于 Demo v0.1-v0.4 + 剧情总纲重设计）

> 本文档基于 `level-redesign-proposal.md` 的重设计总纲更新。
>
> 核心变化：新增 Chair Climb（站上椅子）、Character Switch 四重标识、分阶段教学交互，以及每个交互的"六要素"说明。

---

## 1. 交互设计目标

所有交互必须回答：

> 玩家为什么要做这个动作？
> 玩家在哪里？看到什么？做什么？什么条件触发？触发后发生什么？如何知道成功了？

交互不是为了增加操作数量。本 Demo 的主要交互围绕：

- 移动；
- 观察；
- 调查物件；
- 站上椅子到达高处；
- 感知牵挂线（被动）；
- 控制牵挂线（拉紧/放松）；
- 锚点操作（改变线路径）；
- 角色切换；
- 推重物；
- 安放牵挂线；
- 为他人的线建立连接；
- 触发记忆；
- 收集碎片；
- 聆听回响。

---

## 2. 输入定义

### 2.1 默认输入

| 行为 | 键盘/鼠标 | 手柄 |
|---|---|---|
| 移动 | WASD / 方向键 | 左摇杆 |
| 交互/调查 | E / 鼠标左键 | A |
| 取消 | Esc | B |
| 连接（拖拽） | 鼠标拖拽 | 右扳机+摇杆 |
| 拉紧牵挂线 | 按住鼠标左键（记忆中） | 按住 RT |
| 放松牵挂线 | 松开鼠标左键（记忆中） | 松开 RT |
| 锚点确认 | 靠近锚点 + E | 靠近 + A |
| 触碰牵挂线 | 靠近线 + E | 靠近 + A |
| 安放牵挂线 | 靠近目标物 + E | 靠近 + A |
| 角色切换 | Tab | LB/RB |
| 奔跑 | Shift / 自动触发 | 自动触发 |
| 站上椅子 | 走到椅子旁 + E | 靠近 + A |
| 蹲下钻窄道 | 走到矮洞前自动触发 | 自动触发 |
| 收集碎片 | E（进入范围自动提示） | A |
| 聆听回响 | 停留（无需操作） | 停留 |

实际键位可由技术根据目标平台调整。

### 2.2 输入优先级

当多个交互同时可用时，按以下优先级处理：

1. 剧情触发（最高，锁定输入）
2. 记忆触发（黄色雨伞）
3. 关键机关（踏板、锚点、推重物）
4. 可调查物件
5. 站上椅子
6. 收集碎片/回响点（最低，不抢占其他交互）

## 3. 交互类型（含六要素）

## INT-001｜Inspectable（可调查）

### 适用对象

打包纸箱、行李箱、书桌、柜顶相框、床底耳机、花坛中的钥匙。

### 六要素

| 要素 | 说明 |
|------|------|
| **玩家在哪里** | 关键物件周围 1.5m 范围内 |
| **玩家看到什么** | 物件发出微弱白光，屏幕右下角出现"按 E 调查"提示 |
| **玩家做什么** | 按 E |
| **什么条件触发** | 玩家进入物件交互范围，且该物件未被调查过 |
| **触发之后发生什么** | 播放内心独白文字，物件白光消失，部分物件发生视觉变化 |
| **玩家如何知道自己成功了** | 独白文字出现并 3 秒后淡出；物件不再发光 |

### 特殊规则

- 柜顶相框需要先通过 Chair Climb 站上椅子才能调查。
- 床底耳机需要走到床右侧自动蹲下才能调查。
- 独白文字使用底部居中浮层，不遮挡前方视野和下一个可交互物件的光效。

### 是否阻塞流程

不阻塞。未调查完三件关键物件时，母亲会在 30 秒后自动进入触发剧情。

## INT-002｜Chair Climb（站上椅子）

### 适用对象

女儿房间衣柜旁的木椅。

### 六要素

| 要素 | 说明 |
|------|------|
| **玩家在哪里** | 木椅旁 0.8m 范围内 |
| **玩家看到什么** | 木椅发出微弱白光，屏幕提示"按 E 站上椅子" |
| **玩家做什么** | 按 E |
| **什么条件触发** | 玩家走到木椅旁，且尚未调查柜顶相框 |
| **触发之后发生什么** | 女儿自动站上椅子，高度提升到可调查柜顶相框；相框发出白光 |
| **玩家如何知道自己成功了** | 女儿站上椅子，视野变高，相框出现调查提示 |

### 设计意图

- 替代 Demo 中的跳跃获取，让动作更符合叙事（搬家日整理物品，而不是平台跳跃）。
- 椅子高度固定，玩家不需要判断跳跃时机。

### 是否阻塞流程

不阻塞。柜顶相框是可选记忆碎片，不影响主流程。

## INT-003｜TieLine Perceive（牵挂线被动感知）

### 定义

玩家无需主动操作——牵挂线根据玩家位置/行为自动改变状态。

### 行为

```text
玩家移动改变距离
↓
牵挂线状态自动变化
↓
视觉/音效反馈更新
↓
玩家观察到"世界在回应关系"
```

### 六要素

| 要素 | 说明 |
|------|------|
| **玩家在哪里** | 与母亲/小女儿/锚点之间的距离变化时 |
| **玩家看到什么** | 线的颜色、粗细、抖动程度变化 |
| **玩家做什么** | 移动（被动触发） |
| **什么条件触发** | 玩家与线另一端目标的距离超过阈值 |
| **触发之后发生什么** | 线状态变化，环境响应同步变化 |
| **玩家如何知道自己成功了** | 通过线的视觉/音效变化感知距离关系 |

### 牵挂线四态系统

| 状态 | 视觉表现 | 音效 | 触发条件 | 对应理解 |
|------|----------|------|----------|----------|
| Hidden | 完全不可见 | 无 | Act 1 初期 | 玩家尚不知线的存在 |
| Tense | 粗实线，偏白/红，抖动 | 低频嗡鸣 | 距离增加（Act 1）/ 拉紧操作（Act 2） | "线是束缚" |
| Adjustable | 柔和线，偏暖，出现锚点标记 | 温暖低频音 | Act 2 记忆中 / Act 3 回到现实 | "线可以调整" |
| Extending | 极细线，偏暖金，无限延伸 | 无阻力音，安静 | Act 4 奔跑 | "线支持远行" |

### 设计原则

- 牵挂线状态变化不可逆地随剧情推进——不提供"回退"
- 状态变化有过渡动画（1-2 秒渐变），不突变
- 状态变化伴随环境响应（见 INT-012）

## INT-004｜TieLine Control（牵挂线主动控制）

### 定义

玩家在第二章记忆中作为年轻母亲，可以主动控制牵挂线。

### 六要素

| 要素 | 说明 |
|------|------|
| **玩家在哪里** | Act 2 记忆场景中，母亲靠近小女儿 |
| **玩家看到什么** | 线在小女儿远离时变红、变粗、抖动 |
| **玩家做什么** | 按住鼠标左键/RT 拉紧；松开放松 |
| **什么条件触发** | 小女儿自动往前走，距离增加 |
| **触发之后发生什么** | 拉紧时女儿停下；放松时女儿继续走 |
| **玩家如何知道自己成功了** | 女儿行为符合预期；线颜色/音效反馈明确 |

### 视觉反馈

| 操作 | 线视觉 | 女儿行为 | 音效 |
|------|--------|----------|------|
| 拉紧 | 变粗、变白/红、抖动 | 停下 | 张力音 + 低频嗡鸣 |
| 放松 | 变细、变柔、偏暖 | 继续走 | 脚步声 + 轻柔音 |
| 过度拉紧 | 剧烈抖动 | 女儿回头看 | 警告音 |

### 设计原则

- 拉紧/放松是连续操作，不是开关
- 拉紧有"安全范围"——过度拉紧会触发警告但不会伤害女儿
- 目的是让玩家体验"保护与放手之间的平衡"
- 零失败——女儿被障碍挡住只是停下，不受伤

## INT-005｜Anchor Point（锚点操作）

### 定义

关卡中可以改变牵挂线路径的固定物体。玩家将线绕过锚点后，线的有效距离增加，张力分布改变。

### 六要素

| 要素 | 说明 |
|------|------|
| **玩家在哪里** | 锚点物（路灯、雨伞、花坛）周围 2m 内 |
| **玩家看到什么** | 锚点发出脉动光；线出现虚线预览 |
| **玩家做什么** | 按 E 确认锚点 |
| **什么条件触发** | 玩家靠近可作为锚点的物体 |
| **触发之后发生什么** | 线在锚点处弯折；锚点灯光增强；路径改变 |
| **玩家如何知道自己成功了** | 线明显弯折；锚点灯光增强；成功音效 |

### 锚点清单

| 锚点 | 出现章节 | 功能 | 空间位置 | 引导方式 |
|------|----------|------|----------|----------|
| 路灯 1 | Act 2 | 改变线路径，让女儿绕过水坑 | 记忆场景中段 | 脉动暖光 + 线虚线预览 |
| 路灯 2 | Act 2 | 改变线路径，让女儿绕过台阶/快递柜 | 记忆场景后段 | 脉动暖光 + 线虚线预览 |
| 黄色雨伞 | Act 3 | 女儿将牵挂线挂在伞上 | 鞋柜旁 | 呼吸式光效 + 线端点微光 |
| 花坛 | Act 3 | 路人失物的连接端点 | 街道花坛 | 微弱光线 |

### 设计原则

- 锚点操作在第二章教学，第三章应用——形成学习闭环
- 锚点操作不可撤销（线一旦绕过锚点就固定）
- 锚点操作有明确的视觉确认（灯光增强 + 线弯折）
- 每个锚点只可使用一次

## INT-006｜Character Switch（角色切换）

### 定义

在第二章和第三章前半，玩家可以按 Tab 切换控制母亲或女儿。

### 六要素

| 要素 | 说明 |
|------|------|
| **玩家在哪里** | 双人场景中（Act 2、Act 3 前半） |
| **玩家看到什么** | 当前控制角色有四重标识（见下） |
| **玩家做什么** | 按 Tab |
| **什么条件触发** | 玩家随时可切换（空中/锚定状态除外） |
| **触发之后发生什么** | 控制对象切换，相机轻微偏移，HUD 更新 |
| **玩家如何知道自己成功了** | 标识明确切换；HUD 显示当前角色名 |

### 当前角色四重标识

| 标识 | 表现 |
|------|------|
| 轮廓发光 | 当前控制角色边缘有 2-3px 的发光描边 |
| 角色名高亮 | 角色头顶名字使用亮色/加粗 |
| 屏幕边缘色光 | 屏幕左右边缘出现与角色同色的 subtle 光晕 |
| 相机偏移 | 相机构图轻微向当前角色偏移约 5% |

### 不可切换状态

- 角色处于空中时
- 角色处于锚定状态时
- 剧情演出锁定输入时

### 设计意图

解决 Demo 中"切换人物标识不明显"的问题，让玩家一眼就能知道当前控制谁。

## INT-007｜Heavy Push（推重物）

### 定义

母亲可以推动自行车、箱子等重物，女儿无法推动。

### 六要素

| 要素 | 说明 |
|------|------|
| **玩家在哪里** | 重物旁 0.5m 内，且当前控制角色是母亲 |
| **玩家看到什么** | 重物发出白光，提示"按方向键推动" |
| **玩家做什么** | 按住方向键向目标方向移动 |
| **什么条件触发** | 母亲接触到重物侧面 |
| **触发之后发生什么** | 重物随母亲移动；到达指定位置后自动固定 |
| **玩家如何知道自己成功了** | 重物到达目标位置（如路边、踏板上、断口下）；路通/门开 |

### 应用场景

| 场景 | 重物 | 目标位置 | 结果 |
|------|------|----------|------|
| Act 2 自行车 | 倒下的自行车 | 路边 | 路中央清空 |
| Act 3 仓库 | 箱子 1 | 踏板上 | 门打开 |
| Act 3 仓库 | 箱子 2 | 断口下 | 形成垫脚平台 |

### 设计原则

- 只有母亲能推重物，女儿推时会有"推不动"的动画反馈
- 重物推到目标位置后自动吸附，无需精确对齐
- 这是"各尽所能"主题的玩法体现

## INT-008｜Memory Trigger（记忆触发）

### 定义

特殊交互。触碰到黄色雨伞时进入记忆。

### 六要素

| 要素 | 说明 |
|------|------|
| **玩家在哪里** | 黄色雨伞旁 1.5m 内 |
| **玩家看到什么** | 雨伞发出呼吸式暖光，提示"按 E 触碰" |
| **玩家做什么** | 按 E |
| **什么条件触发** | Act 1 被拉回后，玩家走到雨伞旁 |
| **触发之后发生什么** | 锁定输入 → 雨伞特写 → 雨声 → 叠化 → 进入记忆 |

4. 当前场景与记忆场景叠化
5. Camera 平滑移动
6. 玩家进入记忆状态——视角切换为年轻母亲

## INT-009｜TieLine Attach（线安放）

### 定义

玩家将自己的牵挂线固定在某个物体上，为自己添加锚点。

### 六要素

| 要素 | 说明 |
|------|------|
| **玩家在哪里** | 黄色雨伞旁 1.5m 内 |
| **玩家看到什么** | 雨伞呼吸式光效；线端点发出微光 |
| **玩家做什么** | 按 E 安放线 |
| **什么条件触发** | Act 3 回到现实后，玩家靠近雨伞 |
| **触发之后发生什么** | 线固定在伞上；伞轻微发光；线张力降低 |
| **玩家如何知道自己成功了** | 线端点固定在伞上；伞发出持续微光；安心音效 |

### 应用场景

| 场景 | 目标物 | 效果 |
|------|--------|------|
| Act 3 玄关 | 黄色雨伞 | 女儿牵挂线挂在伞上——不再阻碍移动，但不断裂 |

### 设计意图

玩家在第二章学到"锚点可以改变线路径"，在第三章将这个知识应用到自己的牵挂线上——把牵挂安放在不阻碍自己的位置。不是切断关系，而是重新定义连接方式。

## INT-010｜Echo Connect（为他人的线建立连接）

### 定义

玩家发现他人（路人）与失物之间存在微弱的牵挂线，需要找到另一个端点并建立连接。

### 六要素

| 要素 | 说明 |
|------|------|
| **玩家在哪里** | 街道，路人附近 |
| **玩家看到什么** | 路人身上发出微弱牵挂线，指向花坛方向 |
| **玩家做什么** | 走向花坛，找到钥匙，按 E 建立连接 |
| **什么条件触发** | 玩家走出家门后 3 秒，路人出现；玩家靠近路人 5m 内线可见 |
| **触发之后发生什么** | 钥匙发出清脆声音；路人循声找到钥匙 |
| **玩家如何知道自己成功了** | 路人表情变化（困惑→释然）；女儿内心独白出现 |

### 设计原则

- 路人不知道女孩做了什么——世界因这份连接恢复了完整
- 这个操作是本 Demo 的核心情感节拍之一——从"个人关系"扩展到"世界的连接"
- 寻物不是任务，不显示任务 UI——自然发生
- 路人找到钥匙后的表情变化是唯一反馈

## INT-011｜Memory Fragment（记忆碎片）

### 定义

散布在关卡中的可收集叙事元素。

### 六要素

| 要素 | 说明 |
|------|------|
| **玩家在哪里** | 碎片周围 1m 内 |
| **玩家看到什么** | 碎片发出微弱光，提示"按 E 收集" |
| **玩家做什么** | 按 E |
| **什么条件触发** | 玩家进入碎片范围 |
| **触发之后发生什么** | 播放极短内心独白，碎片标记为已收集 |
| **玩家如何知道自己成功了** | 独白出现，碎片光效消失 |

### 碎片清单

| ID | 对象 | 位置 | 内心独白 | 叙事含义 |
|----|------|------|----------|----------|
| MF-01 | 旧车票 | 女儿房间桌面 | "这是妈妈送我去学校的路。" | 送别的记忆 |
| MF-02 | 身高刻度 | 门框旁 | "又长高了。" | 成长的痕迹 |
| MF-03 | 旧雨靴 | 玄关角落 | "小时候我最讨厌穿雨靴。" | 童年的雨天 |
| MF-04 | 柜顶相框 | 衣柜顶部 | "小学春游的合影。她站在最后一排，手一直悬在我肩膀上方，没敢搭下来。" | 母爱的克制 |
| MF-05 | 床底耳机 | 床底 | "找了一星期，原来在这儿。……这种地方也就我能进来。" | 私密空间 |

### 设计原则

- 记忆碎片是可选内容，不影响主流程
- 每个碎片补充母女关系的细节，不增加新机制
- 收集碎片会在结尾产生微妙变化（牵挂线颜色变化）
- Demo 中设置 5 个碎片
- 已收集的碎片在场景中保留但不再可交互

### 终局影响

| 收集数量 | 结尾呈现 |
|----------|----------|
| 0-1 | 牵挂线银色，柔和延伸 |
| 2-3 | 牵挂线银色，略带暖色 |
| 4-5（全部） | 牵挂线金色，更温暖 |

## INT-012｜Resonance Object（共鸣对象）

### 定义

当牵挂线处于特定状态时，环境中的某些对象会产生响应。

### 六要素

| 要素 | 说明 |
|------|------|
| **玩家在哪里** | 共鸣对象附近 |
| **玩家看到什么** | 对象根据线状态发光/摇动/发出声音 |
| **玩家做什么** | 无（自动触发） |
| **什么条件触发** | 牵挂线状态变化 |
| **触发之后发生什么** | 对象产生视觉/音效响应 |
| **玩家如何知道自己成功了** | 观察到环境在"回应"关系变化 |

### 共鸣对象清单

| 对象 | 位置 | 响应状态 | 响应表现 |
|------|------|----------|----------|
| 墙上旧照片 | 女儿房间走廊 | Tense | 照片微微发光 |
| 窗台植物 | 女儿房间 | Tense → Adjustable | 叶子轻微摇动→叶片舒展 |
| 风铃 | 客厅入口 | Tense | 剧烈响动 |
| 路灯（记忆中） | 记忆场景 | Adjustable | 发出脉动暖光，暗示可交互 |
| 鞋柜上的雨伞 | 玄关 | Adjustable | 呼吸式光效，暗示可安放线 |
| 花坛 | 街道 | Adjustable | 发出微弱光线，暗示失物端点 |

### 设计原则

- 共鸣响应不阻塞流程
- 响应是"环境对玩家行为的确认"，不是必须操作
- 每个共鸣对象都承载一小段叙事碎片
- 共鸣响应不需要玩家交互——自动触发

## INT-013｜Echo Point（回响点）

### 定义

关卡中的特定位置，玩家站定时会听到过去的声音片段。

### 六要素

| 要素 | 说明 |
|------|------|
| **玩家在哪里** | 回响区域 |
| **玩家看到什么** | 无明显视觉提示（故意） |
| **玩家做什么** | 停留超过 1.5 秒 |
| **什么条件触发** | 玩家进入回响区域并停留 |
| **触发之后发生什么** | 环境音降低，播放过去的声音片段 |
| **玩家如何知道自己成功了** | 听到模糊遥远的过去声音 |

### 回响点清单

| ID | 位置 | 声音内容 | 持续时间 |
|----|------|----------|----------|
| EP-01 | 厨房区域 | 母亲喊"吃饭了" | 3s |
| EP-02 | 门口区域 | 小时候女儿说"我回来啦" | 3s |
| EP-03 | 玄关鞋柜旁 | 母亲哼歌 | 5s |

### 设计原则

- 回响点不需要交互操作，只需要"停留"
- 声音片段应该模糊、遥远，像记忆而非对话
- 每个回响点只触发一次
- 不显示 UI 提示——让玩家自然发现
- 如果在进入记忆前发现了全部 3 个回响点，童年记忆场景增加一段雨声+哼唱层

## 4. 牵挂线交互详解

### 4.1 被动感知（Act 1, Act 3, Act 4）

玩家无需操作。牵挂线根据玩家与母亲的距离自动改变状态。

| 距离 | 线状态 | 反馈 |
|------|--------|------|
| 近距离 | Hidden / Adjustable | 无特殊反馈 |
| 中距离 | Tense（Act 1）/ Adjustable（Act 3） | 线可见，轻微张力 |
| 远距离 | Tense 增强（Act 1）→ 拉回 | 阻力产生 |
| 极远距离 | Extending（Act 4） | 无阻力，线无限延伸 |

### 4.2 主动控制（Act 2）

| 操作 | 输入 | 效果 |
|------|------|------|
| 拉紧 | 按住 | 女儿停下 |
| 放松 | 松开 | 女儿走 |
| 锚点 | 靠近+E | 线绕过锚点 |

### 4.3 线安放（Act 3）

| 操作 | 输入 | 效果 |
|------|------|------|
| 触碰线 | 靠近线+E | 线脉动反馈，母亲回应 |
| 挂在雨伞 | 靠近伞+E | 线固定在伞上 |

### 4.4 为他人连接（Act 3）

| 操作 | 输入 | 效果 |
|------|------|------|
| 发现路人线 | 自动 | 看到微弱线 |
| 找到钥匙端点 | 走向花坛 | 钥匙发光 |
| 建立连接 | 靠近+E | 钥匙发出声音，路人找到 |

---

## 5. 连接限制

Prototype 默认：
- Act 1：无主动连接（仅被动感知）
- Act 2：同时最多 1 条主动控制线（牵挂线）
- Act 3：同时最多 2 条连接（自己的线 + 路人的线）
- Act 4：无操作（仅奔跑）

冷却：0.5 秒。

## 6. 交互反馈

### 6.1 三层反馈系统

| 反馈层级 | 触发条件 | 表现 | 优先级 |
|----------|----------|------|--------|
| L1 即时 | 任何交互完成 | 对象视觉变化 + 音效 | 必须 |
| L2 环境级 | 牵挂线状态变化 | 共鸣对象响应 + 色温变化 | 推荐 |
| L3 情感级 | 关键叙事节点 | 镜头微调 + 音乐变化 + 粒子效果 | 关键节点必须 |

### 6.2 成功反馈示例

| 交互 | L1 即时 | L2 环境 | L3 情感 |
|------|---------|---------|---------|
| 调查纸箱 | 纸箱白光消失 | 无 | 独白 |
| 推自行车 | 自行车靠到路边 | 路通 | 小女儿对白 |
| 线绕过路灯 | 线弯折 + 灯光增强 | 路灯暖光扩散 | 成功音效 |
| 线挂在雨伞 | 线固定 + 伞发光 | 玄关变暖 | 安心音效 |
| 路人找到钥匙 | 钥匙清脆声 | 路人表情变化 | 女儿独白 |

## 9. 交互验收

每个交互必须能够回答：

- 什么时候可交互？
- 玩家如何知道可交互？
- 玩家按什么？
- 成功是什么？
- 失败是什么？
- 是否可以重复？
- 是否阻塞流程？
- 触发哪个事件 ID？
- 是否有环境响应？
- 是否属于可选内容？
- 在哪个 Act 可用？

如果这些信息不完整，则交互规格尚未完成。

## 10. 三层引导体系

### 10.1 空间引导层（最底层，玩家无感知）

| 引导手段 | 应用场景 | 表现 |
|----------|----------|------|
| 光线引导 | 全关卡 | 关键路径区域光照亮度比可选路径高 20% |
| 空间收窄 | 章节过渡 | 走廊在关键方向收窄，暗示前进方向 |
| 色温对比 | 谜题区域 | 目标物件区域色温偏暖（吸引），背景偏冷（后退） |
| 物件高度差 | 女儿房间 | 三件关键物件按由低到高排列，暗示调查顺序 |
| 视觉地标 | 全关卡 | 出口方向有一个高亮视觉锚点（如远处的光） |

### 10.2 环境引导层（中层，通过物件行为暗示）

| 引导手段 | 应用场景 | 表现 |
|----------|----------|------|
| 牵挂线方向 | Act 1 | 线的走向自然指向母亲——暗示"回头看" |
| 路灯脉动光 | Act 2 | 可作为锚点的路灯发出脉动暖光 |
| 路灯虚线预览 | Act 2 | 靠近路灯时线显示绕过后的路径 |
| 雨伞呼吸光 | Act 3 | 鞋柜上的雨伞发出呼吸式光效，暗示"来安放线" |
| 花坛微光 | Act 3 | 花坛发出微弱光线，暗示失物端点 |
| 线张力反馈 | Act 1/2 | 拉紧时线抖动+音效，暗示"可以调整" |
| 线端点微光 | Act 3 | 牵挂线端点发出微光，暗示"可安放" |
| 角色轮廓发光 | Act 2/3 | 当前控制角色高亮 |

### 10.3 叙事引导层（顶层，通过对白暗示）

| 引导手段 | 应用场景 | 表现 |
|----------|----------|------|
| 母亲自然对白 | Act 1 | "东西都带了吗？"——暗示可以调查物件 |
| 母亲情感对白 | Act 1 | "别走太远。"——暗示距离有影响 |
| 记忆引导对白 | Act 2 | 年幼女儿"我要过去！"——暗示需要操作 |
| 小女儿反馈对白 | Act 2 | "妈妈好厉害！"——确认推自行车成功 |
| 情感确认对白 | Act 3 | 母亲"路上小心。"/ 女儿"嗯，妈妈。你也照顾好自己。"——暗示关系转变 |
| 线索对白 | Act 3 | 路人"我的钥匙……好像掉在附近了。"——暗示寻找方向 |
| 认知反转对白 | Act 4 | 女儿"线……在延伸？"——暗示规则改变 |
