# 谜题设计｜Puzzle Design（基于 Demo v0.1-v0.4 + 剧情总纲重设计）

> 本文档基于 `level-redesign-proposal.md` 的重设计总纲更新。
>
> 核心变化：
> 1. P001 增加 Chair Climb 机制，高处探索不再依赖跳跃；
> 2. P002 拆分为四个阶段（推自行车 → 水坑 → 快递柜 → 路灯锚点），降低第二章开场认知负荷；
> 3. P003 在路人寻物前增加"走出家门"的合作关卡作为过渡；
> 4. 每个谜题按六要素描述：玩家在哪里、看到什么、做什么、什么条件触发、触发之后发生什么、如何知道自己成功了。

# 总览

本 Demo 包含三个核心谜题，分布在三幕中，形成"探索→机制学习→应用"的递进结构：

| 谜题 ID | 名称 | 所在章节 | 谜题类型 | 难度 | 时长 |
|---------|------|----------|----------|------|------|
| P001 | 离家前的房间 | Act 1 | 环境调查 | 低 | 0:30-0:45 |
| P002 | 保护与放手 | Act 2 | 机制操作（分四阶段） | 中→高 | 1:30-2:00 |
| P003 | 路人的钥匙 | Act 3 | 应用解谜 | 低-中 | 0:30-0:45 |

设计原则：
- 三个谜题共用同一核心机制——牵挂线——但呈现方式不同
- 谜题之间有教学递进关系：P001 建立→P002 教学→P003 应用
- 所有谜题零失败——不 Game Over，只产生"没有正面反馈"

# P001｜离家前的房间

## 1. 谜题定位

P001 不是传统意义的"谜题"——它是一个环境调查体验。

目的不是考验玩家推理，而是让玩家通过调查三件关键物件，自然建立对母女关系的理解，为后续牵挂线的出现做情感铺垫。

## 2. 玩家目标

调查房间中的三件关键物件，理解母女关系。

无强制顺序——玩家可以自由选择调查顺序。但物件的空间排列暗示了一个自然的调查路径。

## 3. 六要素

| 要素 | 说明 |
|------|------|
| **玩家在哪里** | 女儿房间，约 8m × 5m 的空间 |
| **玩家看到什么** | 三件关键物件（打包纸箱、行李箱、书桌）发出白光；门口有暖光；衣柜旁有一把木椅 |
| **玩家做什么** | 走到物件旁按 E 调查；可选地站上椅子调查柜顶相框；蹲下到床底拿耳机 |
| **什么条件触发** | 玩家进入物件 1.5m 范围；30 秒倒计时后母亲自动进入 |
| **触发之后发生什么** | 播放内心独白；被调查物件白光消失；母亲进入并触发雨伞冲突剧情 |
| **玩家如何知道自己成功了** | 三件关键物件都被调查后，母亲从门口进入；或 30 秒后母亲进入 |

## 4. 谜题场景

场景：女儿房间。

### 关键物件

| 物件 | 空间位置 | 调查反馈 | 叙事含义 |
|------|----------|----------|----------|
| 打包纸箱 | 房间左侧地面 | "深色外套、耳机和诗集。离开比想象中容易。" | 女儿已准备好独立 |
| 行李箱 | 房间右侧地面 | "胃药、水果、保温杯……妈妈又塞了这些东西。" | 母亲照顾侵入女儿边界 |
| 书桌 | 房间中央靠墙 | "清空后的桌面留下浅色印记。有些东西带不走，也会留下痕迹。" | 过去的痕迹无法完全抹去 |

### 空间布局

```text
          [书桌]
       ┌──────────┐
       │  (靠墙)   │
       └──────────┘
       
  [打包纸箱]          [行李箱]
   (左侧地面)        (右侧地面)
   
   [衣柜+木椅]                      [床]
   (左侧靠墙)                      (右侧靠墙)
       
         [门口方向 →]
```

### 布局设计意图

- 三件物件形成自然的三角动线——玩家进入房间后会自然走过三件物件
- 打包纸箱在入口左侧——最先被注意到
- 行李箱在入口右侧——与纸箱形成对比（女儿的秩序 vs 母亲的侵入）
- 书桌在正前方——作为视觉焦点引导玩家深入房间
- 衣柜和木椅在左侧——暗示"高处有可调查物"
- 床在右侧——暗示"低处/隐蔽处有可调查物"
- 出口（门口方向）在正下方——暗示"最终要离开"

## 5. Chair Climb 子谜题

### 5.1 玩家在哪里

衣柜旁，木椅旁边。

### 5.2 玩家看到什么

- 衣柜顶部有一个旧相框，发出微弱白光。
- 木椅在衣柜旁，高度约 0.8m。
- 屏幕提示"按 E 站上椅子"。

### 5.3 玩家做什么

玩家走到木椅旁按 E，女儿自动站上椅子。

### 5.4 什么条件触发

- 玩家进入木椅 0.8m 范围内。
- 柜顶相框尚未被调查。

### 5.5 触发之后发生什么

1. 女儿站上椅子，高度提升到柜顶。
2. 相框的调查提示出现。
3. 玩家按 E 调查相框。
4. 播放内心独白。

### 5.6 玩家如何知道自己成功了

- 女儿站上椅子，视野变高。
- 相框出现"按 E 调查"提示。
- 调查后独白出现。

### 5.7 设计意图

- 替代跳跃，让动作符合叙事。
- 椅子是家中常见物件，增强真实感。

## 6. 引导设计

P001 不需要复杂引导——空间本身就在说话。

| 引导手段 | 表现 |
|----------|------|
| 光线引导 | 三件物件区域光照比其他区域高 20% |
| 空间布局 | 三角动线暗示调查顺序 |
| 母亲进入 | 调查完物件后母亲自然进入——暗示"该往前走了" |
| 门口光线 | 门口方向有微弱暖光——暗示"出口在那边" |
| 木椅白光 | 暗示"这个物件可交互" |

## 7. 完成条件

玩家调查至少一件关键物件后，母亲进入房间并放下雨伞。玩家走向门口方向触发 L01-002。

## 8. 失败条件

无。玩家可以花任意时间在房间中探索。不调查任何物件也不会阻止流程——母亲会在 30 秒后自然进入。

## 9. 可选内容

| 内容 | 位置 | 触发条件 |
|------|------|----------|
| 记忆碎片 MF-04（柜顶相框） | 衣柜顶部 | 站上椅子后调查 |
| 记忆碎片 MF-05（床底耳机） | 床底 | 走到床右侧自动蹲下调查 |
| 回响点 EP-01（母亲喊"吃饭了"） | 房间靠近厨房方向 | 站定 1.5 秒 |

# P002｜保护与放手

## 1. 谜题定位

P002 是本 Demo 的核心机制教学谜题。

玩家在童年记忆中扮演年轻母亲，分四个阶段学习：推重物、线的张力、角色切换、锚点操作。

目的不是考验操作技巧，而是让玩家体验"保护与放手之间的平衡"——对应第二章主题"牵挂可以调整"。

## 2. 玩家目标

引导年幼女儿绕过障碍，从起点到达终点。

## 3. 谜题场景

场景：童年记忆中的雨中街道（2D 侧视角）。

### 场景布局

```text
[起点]     [自行车]     [水坑]     [快递柜]     [路灯/断口]     [终点]
  母亲───●───────●───────●───────●─────────●─────────●
         │       │       │       │           │
         │       │       │       │           └── 小女儿到达
         │       │       │       │
         │       │       │       └── 小女儿钻缺口踩踏板开门
         │       │       │
         │       │       └── 走近让线松弛，小女儿绕过
         │       │
         │       └── 母亲推到路边
         │
         └── 小女儿原地等待
```

### 场景元素

| 元素 | 位置 | 功能 |
|------|------|------|
| 年幼女儿 | 场景左侧 | 玩家引导的目标角色 |
| 年轻母亲（玩家） | 场景最左侧 | 玩家控制角色 |
| 牵挂线 | 母亲↔女儿 | 可拉紧/放松/锚点操作 |
| 自行车 | 起点右侧 | 重物，只有母亲能推 |
| 水坑 | 场景前段 | 障碍1——需要线松弛让女儿绕过 |
| 快递柜 | 场景中段 | 障碍2——缺口只有小女儿能钻 |
| 路灯 | 场景后段 | 锚点——改变线路径 |
| 断口/台阶 | 路灯附近 | 障碍3——需要锚定借跳 |
| 终点 | 场景最右侧 | 女儿的目标位置 |

## 4. 分阶段教学

### 阶段 A：推自行车（推重物教学）

#### 六要素

| 要素 | 说明 |
|------|------|
| **玩家在哪里** | 记忆街道起点，自行车前 |
| **玩家看到什么** | 自行车横在路中央，发出白光；小女儿在后方原地等待 |
| **玩家做什么** | 控制母亲走到自行车旁，按方向键推到路边 |
| **什么条件触发** | 母亲接触到自行车侧面 |
| **触发之后发生什么** | 自行车移到路边；小女儿开始自动往前走 |
| **玩家如何知道自己成功了** | 路中央清空；小女儿说"妈妈好厉害！" |

#### 设计意图

- 先让小女儿在原地等待，避免玩家同时处理"推重物"和"控制线"两个信息。
- 让玩家先理解"母亲能推重物"这一角色差异。

### 阶段 B：水坑（线的张力教学）

#### 六要素

| 要素 | 说明 |
|------|------|
| **玩家在哪里** | 自行车后，街道前段 |
| **玩家看到什么** | 水坑横在路中；小女儿往前走，线逐渐绷紧 |
| **玩家做什么** | 走近小女儿让线松弛，或按住拉紧让女儿停下 |
| **什么条件触发** | 小女儿到达水坑前；或母亲与小女儿距离超过 REST |
| **触发之后发生什么** | 线松弛时女儿绕过水坑；线太紧时女儿停下 |
| **玩家如何知道自己成功了** | 女儿绕过水坑继续走；母亲说"松开不代表失去连接" |

#### 卡点控制

| 时间 | 触发条件 | 提示内容 | 提示类型 |
|------|----------|----------|----------|
| 0s | 女儿遇到水坑 | 无提示 | — |
| 8s | 女儿停在水坑前 | 小女儿头顶出现"停"示意；线变红 | 环境引导 |
| 15s | 仍无进展 | 屏幕提示"走近她，让线松弛" | 叙事引导 |
| 25s | 仍无进展 | 母亲内心独白"也许……走近一点？" | 叙事引导 |

### 阶段 C：快递柜缺口（角色切换教学）

#### 六要素

| 要素 | 说明 |
|------|------|
| **玩家在哪里** | 水坑后，街道中段 |
| **玩家看到什么** | 快递柜挡住去路，底部有矮洞；右侧闸门关闭 |
| **玩家做什么** | 按 Tab 切换到小女儿，钻过缺口踩踏板 |
| **什么条件触发** | 母亲走到快递柜前无法前进 |
| **触发之后发生什么** | 闸门打开；切换回母亲通过 |
| **玩家如何知道自己成功了** | 闸门打开；踏板显示"已压住" |

#### 角色切换引导

- 母亲无法前进时，屏幕提示"按 Tab 切换到小女儿"。
- 切换后，小女儿轮廓发光、屏幕边缘色光、角色名高亮。
- 小女儿走到矮洞前自动蹲下钻过。

### 阶段 D：路灯锚点（锚点操作教学）

#### 六要素

| 要素 | 说明 |
|------|------|
| **玩家在哪里** | 闸门后，街道后段 |
| **玩家看到什么** | 断口/台阶在前方；路灯发出脉动光；线显示虚线预览 |
| **玩家做什么** | 母亲靠近路灯按 E 锚定；切换小女儿借线跳/爬过去 |
| **什么条件触发** | 母亲进入路灯 2m 范围 |
| **触发之后发生什么** | 线在路灯处弯折；小女儿成功到达对岸 |
| **玩家如何知道自己成功了** | 线明显弯折；路灯灯光增强；小女儿说"我过来啦！" |

#### 锚点引导

- 路灯发出脉动暖光。
- 靠近路灯时，线显示虚线预览（绕过路灯后的路径）。
- 按 E 后，线在路灯处弯折，灯光增强。

## 5. 解谜流程（完整）

```text
1. 起点：母亲控制，小女儿原地等待
   ↓
2. 推自行车到路边 → 小女儿开始走
   ↓
3. 水坑前：走近让小女儿绕过
   ↓
4. 快递柜前：Tab 切换小女儿钻缺口踩踏板 → 闸门开
   ↓
5. 路灯前：母亲锚定 → 小女儿借线跳过断口
   ↓
6. 小女儿到达终点，母亲目送
```

## 6. 引导设计

### 空间引导层

| 引导手段 | 表现 |
|----------|------|
| 自行车白光 | 提示可推动 |
| 水坑反光 | 提示障碍 |
| 路灯脉动光 | 提示可交互 |
| 线张力方向 | 线绷紧时弯折方向指向最近路灯 |
| 女儿朝向 | 女儿停下时面朝障碍物另一侧——暗示"需要绕过" |

### 环境引导层

| 引导手段 | 表现 |
|----------|------|
| 路灯靠近增强 | 玩家靠近路灯时光效增强 |
| 锚点预览 | 靠近路灯时线出现"可弯折"的虚线预览 |
| 成功反馈 | 锚点操作成功后路灯灯光增强 + 成功音效 |
| 角色切换标识 | 四重标识确保玩家知道当前控制谁 |

### 叙事引导层

| 引导手段 | 表现 |
|----------|------|
| 女儿对白 | "我要过去！"——暗示需要操作 |
| 母亲内心独白 | "拉得太紧，她走不动。放太松，她可能摔倒。"——暗示平衡 |
| 女儿成功对白 | "我过来啦！"——确认成功 |

## 8. 零失败设计

- 女儿被障碍挡住只是停下——不受伤、不 Game Over
- 玩家可以反复尝试拉紧/放松/锚点操作
- 无时间限制
- 错误操作（如拉紧过度）只产生警告反馈，不造成后果
- 即使玩家完全不操作，女儿也不会受到伤害——只会停在原地
- 按 R 可以回到最近检查点（Demo 第三章已有）

## 9. 胜利条件

女儿成功绕过所有障碍到达终点。

## 10. 失败条件

无 Game Over。唯一"失败"是女儿停在障碍前不动——玩家需要调整操作。

## 11. 正确反馈

### 推自行车成功

- 自行车靠到墙边（视觉）
- 路中央清空（空间）
- 小女儿说"妈妈好厉害！"（对白）

### 线张力操作成功

- 线变柔/变红（视觉）
- 女儿停下/继续走（动画）
- 母亲说"松开不代表失去连接"（对白）

### 锚点操作成功

- 线在路灯处弯折（视觉）
- 路灯灯光增强（视觉）
- 成功音效（音效）
- 女儿改变方向（动画）

### 女儿到达终点

- 母亲站在路灯旁目送（演出）
- 画面停留 3-5 秒（节奏控制）
- 准备过渡到 Act 3

## 12. 错误反馈

| 行为 | 反馈 |
|------|------|
| 过度拉紧 | 线剧烈抖动 + 警告音——但女儿不受伤 |
| 女儿被障碍挡住 | 女儿停下 + 困惑表情——暗示需要改变策略 |
| 在非锚点位置按 E | 无反馈——不产生错误提示 |
| 切换角色失败 | 屏幕提示"空中/锚定时不能切换" |

# P003｜路人的钥匙

## 1. 谜题定位

P003 是应用型谜题——玩家将在 P002 学到的"锚点/连接"概念应用到新场景。

目的不是考验推理，而是让玩家体验"牵挂不只存在于自己与母亲之间"——对应第三章主题"牵挂属于世界"。

## 2. 玩家目标

发现路人与失物之间的微弱牵挂线，找到失物（钥匙）的另一端，并建立连接。

## 3. 六要素

| 要素 | 说明 |
|------|------|
| **玩家在哪里** | 家门外面的街道 |
| **玩家看到什么** | 路人在翻找口袋；路人身上发出微弱牵挂线指向花坛；花坛发出微光 |
| **玩家做什么** | 走向花坛，找到钥匙，按 E 建立连接 |
| **什么条件触发** | 玩家走出家门后 3 秒路人出现；靠近路人 5m 内线可见 |
| **触发之后发生什么** | 钥匙发出清脆声；路人循声找到钥匙；女儿内心独白 |
| **玩家如何知道自己成功了** | 路人表情变化（困惑→释然）；女儿独白出现；道路畅通 |

## 4. 谜题场景

场景：家门外的街道。

### 场景元素

| 元素 | 位置 | 功能 |
|------|------|------|
| 路人 | 街道中央 | 寻找失物的角色 |
| 路人的牵挂线 | 路人→花坛 | 微弱光线，指向花坛方向 |
| 花坛 | 街道右侧 | 藏有钥匙 |
| 钥匙 | 花坛中 | 连接的目标端点 |

### 空间布局

```text
     [家门口]
         │
    ┌────┴────┐
    │  街道   │
    │         │
    │  [路人]  │        [花坛]
    │   ●───微弱线──→──● (钥匙)
    │         │
    └─────────┘
     [继续前行 →]
```

## 5. 前置过渡：走出家门

在到达街道之前，玩家需要与母亲一起通过三段合作关卡（楼道/仓库/天台）。这三段不是独立谜题，而是 P002 到 P003 的过渡练习：

| 关卡 | 练习的机制 | 与 P002 的关系 |
|------|------------|----------------|
| 楼道与出口 | 锚定借跳、爬线 | P002 阶段 D 的延伸 |
| 仓库 | 推重物、角色切换 | P002 阶段 A/C 的组合 |
| 天台 | 交替锚定接龙 | P002 阶段 D 的高级应用 |

这三段的作用是让玩家在"帮助他人"之前，先和母亲一起熟练掌握牵挂线的各种用法。

## 6. 玩家行为

```text
1. 玩家走出家门，来到街道
   ↓
2. 发现路人——路人在翻找口袋、四处张望
   ↓
3. 玩家看到路人身上发出的微弱牵挂线
   - 线的一端在路人身上
   - 线的另一端指向花坛方向
   ↓
4. 玩家走向花坛
   - 花坛发出微弱光线（环境引导）
   ↓
5. 玩家发现藏在花坛中的钥匙
   - 钥匙发出微光
   ↓
6. 玩家将路人的牵挂线连接到钥匙位置
   - 靠近钥匙 + E
   ↓
7. 钥匙发出清脆声音
   ↓
8. 路人循声找到钥匙
   - 路人表情变化（困惑→释然）
   - 路人不知道女孩做了什么
```

## 7. 引导设计

| 引导类型 | 表现 |
|----------|------|
| 视觉引导 | 微弱牵挂线自然吸引注意——线的光线指向花坛 |
| 环境引导 | 花坛发出微弱光线——暗示失物端点 |
| 叙事引导 | 路人"我的钥匙……好像掉在附近了。"——暗示寻找方向 |

## 8. 卡点控制

| 时间 | 触发条件 | 提示内容 | 提示类型 |
|------|----------|----------|----------|
| 0s | 路人出现 | 无提示——路人行为自然吸引注意 | — |
| 10s | 玩家未注意到路人线 | 路人声音增大（翻找声） | 空间引导 |
| 20s | 玩家注意到线但未找到钥匙 | 花坛光线增强 | 环境引导 |
| 30s | 仍未找到 | 路人"好像在那个方向……"（看向花坛） | 叙事引导 |

## 9. 零失败设计

- 路人的钥匙一定在花坛中——没有干扰选项
- 玩家不可能"找错地方"——微弱线明确指向花坛
- 即使玩家直接走过去，路人也会自然找到钥匙（只是没有玩家的参与）
- 不有时间限制

## 10. 胜利条件

玩家将路人的线连接到钥匙位置，路人找到钥匙。

## 11. 失败条件

无。如果玩家不操作，30 秒后路人会自己找到钥匙——但玩家会错过这个"帮助建立连接"的体验。

## 12. 正确反馈

| 行为 | 反馈 |
|------|------|
| 发现钥匙 | 钥匙发出微光（视觉） |
| 建立连接 | 钥匙发出清脆声音（音效） |
| 路人找到钥匙 | 路人表情变化：困惑→释然（动画） |
| 女儿内心独白 | "原来不只有我和妈妈之间有这种线。"（叙事） |

## 13. 设计意图

P003 的核心不是"解谜"而是"参与"。

路人不知道女孩做了什么——世界因这份连接恢复了完整。玩家从"个人关系"扩展到"世界的连接"。

这个谜题没有干扰项、没有失败惩罚、没有时间压力——它的设计目标是让玩家自然地、无压力地体验"为他人的连接"。

## 14. 参数

| 参数 | 值 | 说明 |
|------|------|------|
| 路人出现时机 | 玩家走出家门后 3 秒 | 给玩家适应街道环境的时间 |
| 线可见距离 | 5m | 玩家靠近路人 5m 内看到微弱线 |
| 花坛引导光范围 | 5m | 玩家靠近花坛 5m 内看到微光 |
| 首次提示 | 10s | 路人翻找声增大 |
| 强提示 | 20s | 花坛光线增强 |
| 终极提示 | 30s | 路人看向花坛 |
| 自解决时间 | 30s | 超时后路人自己找到钥匙 |

# 三个谜题的关系

## 教学递进

```text
P001（Act 1）          P002（Act 2）           P003（Act 3）
环境调查               机制操作                应用解谜
    │                      │                      │
    └── 建立情感 ─────────→├── 学习机制 ─────────→├── 应用机制
                           │                      │
                           ├── 推重物             ├── 帮助他人
                           ├── 线张力             └── 连接世界
                           ├── 角色切换
                           └── 锚点操作
```

## 机制递进

| 谜题 | 核心机制 | 玩家角色 | 失败惩罚 | 难度来源 |
|------|----------|----------|----------|----------|
| P001 | 调查（被动） | 成年女儿 | 无 | 空间认知 |
| P002 | 推重物+线控制+切换+锚点（主动） | 年轻母亲 | 无（女儿停下/回检查点） | 操作学习 |
| P003 | 为他人连接（主动） | 成年女儿 | 无（路人自解决） | 推理（低） |

## 情感递进

| 谜题 | 情感目标 | 对应理解 |
|------|----------|----------|
| P001 | 熟悉、复杂、不舍 | 建立关系认知 |
| P002 | 犹豫→理解→释然 | 牵挂可以调整 |
| P003 | 惊讶→开放 | 牵挂属于世界 |

# 高级玩家挑战

为已经理解机制的玩家保留以下深度：

| 挑战类型 | 内容 | 奖励 |
|----------|------|------|
| 全收集 | 找到全部 5 个记忆碎片 | 结尾牵挂线金色 |
| 全回响 | 站在全部 3 个回响点 | 童年记忆增加雨声+哼唱层 |
| 无提示通关 | 在环境提示增强前完成各谜题 | 隐藏内心独白 |
| P002 最少操作 | 在最少锚点操作下完成 P002 | 无额外奖励——优雅操作本身即是奖励 |
| P003 快速发现 | 在路人出现后 10 秒内找到钥匙 | 无额外奖励——快速发现本身即是奖励 |

# 验收标准

## P001 验收

- [ ] 玩家在 20 秒内开始调查物件
- [ ] 玩家能理解三件物件的叙事含义
- [ ] 无玩家在房间中停留超过 1 分钟仍不知去向
- [ ] 母亲进入时机自然
- [ ] 柜顶相框通过站上椅子获取，不依赖跳跃
- [ ] 独白文字不遮挡下一个可交互物件的光效

## P002 验收

- [ ] 玩家在视角切换后 10 秒内尝试操作线
- [ ] 玩家在路灯旁 15 秒内尝试锚点操作
- [ ] 70% 玩家在 2 分钟内完成 P002
- [ ] 无玩家在 P002 中停留超过 3 分钟仍未完成
- [ ] 女儿停下不产生挫败感
- [ ] 角色切换标识明显，玩家不会迷失控制对象
- [ ] 分阶段教学中每个阶段都有明确成功反馈

## P003 验收

- [ ] 玩家在路人出现后 15 秒内注意到微弱线
- [ ] 玩家在 30 秒内找到花坛中的钥匙
- [ ] 80% 玩家主动建立连接（而非等待路人自解决）
- [ ] 玩家理解"这根线不属于自己"的主题
- [ ] 走出家门的三个合作关卡不造成卡关

## 整体验收

- [ ] 三个谜题的教学递进关系清晰
- [ ] P002 锚点机制在 P003 中有应用
- [ ] 所有谜题零失败——无 Game Over
- [ ] 无玩家在任意谜题中产生明显挫败感
- [ ] 新手玩家在无教程文本情况下可完成全流程
- [ ] 每个关键操作都有明确的成功反馈
