# 谜题设计｜Puzzle Design

# P001｜Memory Lock

## 1. 谜题定位

Memory Lock 是 Demo 的核心谜题。

它的目的不是考验玩家记忆顺序，而是让玩家第一次主动理解：

> 牵挂线可以改变环境，也可以成为进入记忆的钥匙。

## 2. 玩家目标

将三个对象按照正确顺序连接：

```text
A → B → C
```

完成后开启 Memory Door。

---

# 3. 谜题场景

场景中包含：

- Object A：旧相框；
- Object B：家庭桌；
- Object C：黄色雨伞；
- Memory Door：记忆入口。

这些物件必须在视觉上存在合理关联。

玩家应该能够通过环境线索推断顺序，而不是随机试错。

---

# 4. 正确顺序

默认：

```text
A → B → C
```

含义：

```text
家庭照片
↓
共同生活
↓
黄色雨伞
↓
童年记忆
```

因此谜题实际上也是一个非常简化的叙事链。

---

# 5. 线索设计

玩家可以从三个维度获得提示。

## 视觉线索

Object A 与 B 的视觉关联最明显。

Object B 与 C 存在色彩/构图关联。

## 声音线索

靠近正确对象时：

- 环境音轻微变化；
- 出现非常短的提示音。

## 空间线索

三个对象在场景中的排列应该暗示：

```text
过去 → 生活 → 记忆
```

---

# 6. 玩家操作

流程：

```text
选择 A
↓
拖到 B
↓
松开
↓
系统验证
↓
成功
↓
选择 B
↓
拖到 C
↓
成功
```

---

# 7. 正确反馈

第一次正确连接：

- 连接线稳定；
- 对象产生轻微亮起；
- 音效确认；
- 门的状态发生变化。

第二次正确连接：

- 门进一步变化；
- 黄色雨伞获得焦点；
- 最终解锁。

不要立即弹出：

> “Puzzle Complete”

尽量使用环境反馈。

---

# 8. 错误反馈

错误连接：

- 线快速消失；
- 对象轻微抖动；
- 产生低频提示音；
- 不扣生命。

连续三次错误：

> 重置当前谜题状态。

不要让玩家死亡。

---

# 9. 卡点控制

如果玩家超过 20 秒没有进行有效连接：

> 增强正确对象的视觉提示。

如果玩家超过 40 秒仍然没有进展：

> 提供轻微环境提示。

提示不应该直接告诉：

> “A 连 B。”

而应该让玩家意识到：

> “这些东西之间有关联。”

---

# 10. 胜利条件

满足：

```text
A → B
B → C
```

并保持最终连接：

> 2 秒。

然后：

```text
Memory Door = Open
```

---

# 11. 失败条件

本谜题没有 Game Over。

失败只有：

> 当前解谜状态重置。

原因：

本游戏重点是叙事和关系，不应该因为一个简单谜题打断情绪。

---

# 12. 参数

| 参数 | Prototype |
|---|---:|
| 最大主动连接 | 2 |
| 连接冷却 | 0.5s |
| 错误重置次数 | 3 |
| 成功保持时间 | 2s |
| 首次提示 | 20s |
| 强提示 | 40s |

所有参数应集中管理，便于后续调试。

---

# 13. 验收标准

测试者在没有阅读攻略的情况下：

- 能理解三个对象可以连接；
- 能通过环境线索在 1～2 分钟内完成；
- 错误不会造成明显挫败；
- 完成后能理解黄色雨伞与记忆有关。

如果玩家完全靠随机尝试完成，则需要加强线索。
