# 1. 设计意图

## 1.1 玩家幻想

> 我正在经历离开家的那一天——从被束缚到被释放，从个人挣扎到理解关系的普遍性。

玩家不获得新能力，而是经历对同一种连接（牵挂之线）的三次重新理解：

```
束缚 → 可调整的关系 → 属于世界的连接 → 允许彼此远行
```

## 1.2 节奏弧线

```
Tension → Release → Escalation → Climax → Resolution
  第一章       第二章       第三章        第四章     结尾
 (压迫)      (理解)      (开放)       (释放)    (余韵)
```

## 1.3 核心叙事节拍

本 Demo 承载一个完整的情感弧线：

> 离开家，并不意味着失去家。成为独立的人，也不意味着拒绝曾经给予自己力量的关系。

## 1.4 新机制引入

| 机制 | 引入章节 | 教学方式 |
|------|----------|----------|
| 牵挂线感知与张力 | 第一章 | 距离变化自然触发，无文本教学 |
| 牵挂线主动控制（拉紧/放松/锚点） | 第二章 | 环境引导 + 母亲视角操作 |
| 牵挂线共同操作（双人配合） | 第三章前半 | 楼道/仓库/天台三段渐进教学 |
| 为他人的牵挂线建立连接 | 第三章后半 | 路人寻物场景，引导发现 |
| 牵挂线无限延伸 | 第四章 | 奔跑中自然发生 |

# 2. 当前 Demo 问题诊断

基于三个可玩原型（第一章 v0.1、第二章 v0.1、第三章 v0.4）与内部试玩会议记录，识别出以下关键问题：

## 2.1 第一章「离家」

| 问题 | 表现 | 解决方案 |
|------|------|----------|
| 文字遮挡探索 | 调查后的独白/任务提示长时间显示，遮挡了下一个发光可交互物件 | 调查反馈改为**临时浮层**，3 秒后淡出；任务提示移至屏幕右上角且不遮挡关键光效；被拉回后的独白使用底部居中条 |
| 高处探索不自然 | 柜顶相框需要跳跃获取，与叙事中"搬家日整理物品"的氛围不符 | 在衣柜旁放置**木椅**，玩家走到椅子旁按 E「站上椅子」自动到达柜顶高度；移除对跳跃的需求 |
| 探索节奏不清晰 | 5 个物件（床底耳机、柜顶相框等）中部分位置较隐蔽，玩家可能遗漏 | 关键物件按"三角动线"布置；必须调查的核心物件减少到 3 个（纸箱/行李箱/书桌），床底耳机与柜顶相框改为可选记忆碎片 |

## 2.2 第二章「第一次放手」

| 问题 | 表现 | 解决方案 |
|------|------|----------|
| 开场没玩懂 | 玩家进入后同时面对"小女儿会自己走""线会绷紧""要先推自行车"三个信息，认知过载 | **分阶段教学**：阶段 A 先单独推自行车（无小女儿干扰）；阶段 B 再引入小女儿和线的概念 |
| 角色切换不明显 | Tab 切换后，当前角色头顶的小红三角太弱 | 当前控制角色增加**轮廓发光 + 角色名高亮 + 屏幕边缘色光 + 相机轻微偏移**四重标识 |
| 小女儿行为不可预测 | 玩家不知道小女儿什么时候会停、为什么停 | 增加"女儿状态指示器"：当线绷紧时，小女儿头顶出现短暂"停"的示意；遇到障碍时会说"我要过去" |
| 锚点教学跳跃 | 第一次需要绕路灯时，缺少循序渐进的引导 | 增加"线张力预览"：靠近路灯时，线以虚线显示绕过后的路径 |

## 2.3 第三章「一起走一段」

| 问题 | 表现 | 解决方案 |
|------|------|----------|
| 与剧情总纲的"外面的世界"衔接不够直接 | Demo 第三章是双人合作解谜，剧情第三幕是女儿独自帮助路人 | 将第三章拆分为两部分：前半"走出家门"（保留 Demo 第三章的双人合作机制，作为第二章到第三章的过渡）；后半"街道上的牵挂"（新设计路人寻物） |
| 跳跃高度固定后部分平台难以到达 | v0.4 修复了最后跳不上去的问题，但仍需反复尝试 | 所有需要跳跃的几何都提供**椅子/箱子/踏板**作为辅助，或明确标记为"需要借线跳" |

## 2.4 全局问题

| 问题 | 表现 | 解决方案 |
|------|------|----------|
| 缺少"成功确认" | 玩家完成关键操作后，不清楚自己是否做对了 | 每个关键节点增加**明确的正反馈**：物件发光、音效、角色动作、对白、镜头停顿 |
| 视角切换突兀 | 第一章→第二章、第二章→第三章的转场缺少情绪缓冲 | 增加**过渡空间**：雨伞特写/记忆褪色/家门开启三个转场，每个持续 3-5 秒 |
| 牵挂线状态可视化不足 | 玩家难以判断线是"松""紧"还是"极限" | HUD 增加简洁的线状态指示（或完全通过线的视觉表现传达），并在第二章首次绷紧时给出明确反馈 |

# 3. 关卡结构总览

## 3.1 四幕结构与 Demo 对应

游戏 Demo 分为四幕，与剧情总纲对齐。当前三个 Demo 原型分别对应：

| 幕 | 名称 | 主题 | 玩家视角 | 核心机制 | 对应 Demo | 时长 |
|----|------|------|----------|----------|-----------|------|
| 第一幕 | 离家 | 牵挂是束缚 | 成年女儿 | 牵挂线被动感知 | Demo 第一章 | 1:00-1:30 |
| 第二幕 | 第一次放手 | 牵挂可以调整 | 年轻母亲（记忆中） | 牵挂线主动控制 | Demo 第二章 | 1:30-2:00 |
| 第三幕 | 外面的世界 | 牵挂属于世界 | 成年女儿 | 双人合作 + 为他人连接 | Demo 第三章（前半）+ 新设计（后半） | 2:00-2:30 |
| 第四幕 | 向外跑 | 牵挂允许远行 | 成年女儿 | 牵挂线无限延伸 | 新设计 | 0:30-1:00 |

**总时长：5-7 分钟**（Demo 三章合计约 5 分钟，新增路人寻物与结尾约 1-2 分钟）

## 3.2 节点总览

```text
Act 1 — 离家（Demo 第一章 v0.1，修复后）
  L01-001 离开前的家（房间探索）
  L01-002 第一次牵挂（线显现）
  L01-003 第一次分离（线拉回）
    ↓ [过渡1：伞放置]

Act 2 — 第一次放手（Demo 第二章 v0.1，分阶段教学）
  L02-001 黄色雨伞（进入记忆）
  L02-002 自行车（母亲推重物教学）
  L02-003 水坑（线的张力教学）
  L02-004 快递柜缺口（角色切换教学）
  L02-005 路灯锚点（锚点操作教学）
  L02-006 目送（章节收尾）
    ↓ [过渡2：记忆褪色]

Act 3 — 外面的世界（Demo 第三章 v0.4 + 新设计）
  L03-001 楼道与出口（双人合作教学关）
  L03-002 仓库（推箱 + 窄道 + 垫脚）
  L03-003 天台（交替锚定接龙）
    ↓ [走出家门]
  L03-004 街道上的牵挂（路人寻物）
    ↓ [过渡3：街道延伸]

Act 4 — 向外跑（新设计）
  L04-001 重新奔跑
  L04-002 线不断延长
  L04-003 余响
```

## 3.3 形状语言

- **线性叙事**——玩家不选择章节顺序，但每章内有探索空间
- **场景切换**——四幕对应四个物理空间：家、记忆街道、家→楼道→街道、街道远方
- **无 Hub**——不设中心枢纽，流程连续推进

# 4. 维度一：难度曲线优化

## 4.1 难度曲线设计

```
张力/认知负荷
 │
 │          ┌──────────┐
 │         ╱            ╲    ┌──┐
 │    ┌──╲              ╲  ╱    ╲
 │   ╱    ╲              ╲╱      ╲──
 │  ╱                                    ──→
 ──┴───────────────────────────────────────→ 时间
   Act1      Act2          Act3        Act4
   探索     操作+推理      应用+扩展     释放
   低→中     中→高         中→低        低→零
```

### 五段式递进：探索 → 单项机制 → 组合机制 → 应用 → 释放

| 阶段 | 章节 | 难度来源 | 认知负荷 | 失败惩罚 |
|------|------|----------|----------|----------|
| 探索 | Act 1 | 空间认知 + 情感建立 | 低 | 无 |
| 单项机制 | Act 2 前半 | 推重物 / 线张力 / 切换角色 / 锚点，每个单独教 | 中 | 无（零失败） |
| 组合机制 | Act 2 后半 + Act 3 前半 | 组合使用线控制、切换、锚定、推箱 | 中→高 | 无（回检查点） |
| 应用 | Act 3 后半 | 在新场景中为路人建立连接 | 中 | 无 |
| 释放 | Act 4 | 零——纯情感 | 低→零 | 无 |

## 4.2 各章节难度详解

### 第一幕：探索（认知负荷：低）

**玩家行为**：移动、观察、调查物件。

**设计要点**：
- 房间中三个关键物件（打包纸箱、行李箱、书桌）形成自然探索路径
- 空间引导：物件放置暗示行走路线，不需要地图
- 牵挂线在玩家走向门口时自然显现——不是教学，是发现
- 第一次被拉回是叙事事件，不是失败状态
- 高处相框改为"站上椅子"获取，不依赖跳跃技巧

**流失风险**：玩家不理解"为什么被拉回"→ 通过 L01-003 的对白和视觉反馈消解困惑。

### 第二幕：单项→组合机制（认知负荷：中→高）

**玩家行为**：视角切换为年轻母亲；推自行车；控制线的张力；切换角色；利用路灯锚点。

**设计要点**：
- 记忆场景是横向 2D 视角，年幼女儿从左向右行进
- **分阶段教学**：先推自行车（理解"母亲能推重物"）→ 再引入小女儿和线 → 再教学切换 → 最后教学锚点
- 玩家控制母亲手中的牵挂线：按住拉紧（保护）、松开放松（给空间）
- 场景中有路灯柱作为锚点改变线路径
- 目标：让年幼女儿绕过障碍成功前进
- 零失败：女儿被障碍挡住时只是停下，不会受伤或 Game Over

**流失风险**：玩家不理解"拉紧/放松"的操作 → 通过环境引导（路灯发光、线张力视觉反馈）和分阶段教学降低认知门槛。

### 第三幕：应用（认知负荷：中）

**玩家行为**：回到成年女儿视角；与母亲合作走出家门；在街道为路人连接失物。

**设计要点**：
- 前半部分（楼道/仓库/天台）巩固第二章学到的机制，并引入"双人共同用力"的主题
- 后半部分（街道）应用锚点机制：帮助路人找到失物
- 路人寻物是小型应用谜题：看到路人→看到微弱牵挂线→找到另一个端点（花坛中的钥匙）→连接
- 这个谜题没有干扰项——目的不是考验推理，而是让玩家体验"帮助他人建立连接"

**流失风险**：玩家找不到钥匙位置 → 通过牵挂线的视觉指引（微弱光线指向花坛方向）降低难度。

### 第四幕：释放（认知负荷：零）

**玩家行为**：奔跑。

**设计要点**：
- 纯情感体验，无操作挑战
- 玩家期待被拉回（基于第一幕经验）但线不断延长
- 这个"期待落空"本身就是叙事高潮——原来牵挂已经改变
- 女儿跑出画面，线仍然存在

# 5. 维度二：交互元素与环境机制

## 5.1 交互类型总览

| ID | 交互类型 | 引入章节 | 核心行为 |
|----|----------|----------|----------|
| INT-001 | Inspectable（可调查） | Act 1 | 进入范围→提示→确认→播放短反馈 |
| INT-002 | Chair Climb（站上椅子） | Act 1 | 走到椅子旁按 E 自动站上，到达高处 |
| INT-003 | TieLine Perceive（线感知） | Act 1 | 距离变化触发线状态变化 |
| INT-004 | TieLine Control（线控制） | Act 2 | 按住拉紧 / 松开放松 |
| INT-005 | Anchor Point（锚点操作） | Act 2 | 将线绕过锚点改变路径 |
| INT-006 | Character Switch（角色切换） | Act 2 | Tab 切换控制角色 |
| INT-007 | Heavy Push（推重物） | Act 2 | 母亲推动自行车/箱子 |
| INT-008 | Memory Trigger（记忆触发） | Act 1→2 | 触碰黄色雨伞进入记忆 |
| INT-009 | TieLine Attach（线安放） | Act 3 | 将自己的牵挂线挂在物体上 |
| INT-010 | Echo Connect（为他人的线建立连接） | Act 3 | 找到路人失物的另一端并连接 |
| INT-011 | Memory Fragment（记忆碎片） | 全章节 | 可选收集叙事碎片 |
| INT-012 | Resonance Object（共鸣对象） | 全章节 | 牵挂线状态变化时环境物件响应 |

## 5.2 核心机制说明

### 牵挂线四态系统

| 状态 | 视觉表现 | 触发条件 | 对应理解 |
|------|----------|----------|----------|
| Hidden（隐藏） | 完全不可见 | Act 1 初期 | 玩家尚不知线的存在 |
| Tense（绷紧） | 粗实线，抖动，张力音效 | 距离增加 / 拉紧操作 | "线是束缚" |
| Adjustable（可调） | 线出现锚点标记，颜色偏暖 | Act 2 记忆中 / Act 3 回到现实 | "线可以调整" |
| Extending（延伸） | 细长柔和线，无限延伸，无阻力 | Act 4 | "线支持远行" |

### 锚点系统

锚点是关卡中可以改变牵挂线路径的固定物体。

| 锚点 | 出现章节 | 功能 | 空间位置 |
|------|----------|------|----------|
| 路灯 1 | Act 2 | 改变线路径，让女儿绕过水坑 | 记忆场景中段 |
| 路灯 2 | Act 2 | 改变线路径，让女儿绕过台阶/快递柜 | 记忆场景后段 |
| 黄色雨伞 | Act 3 | 女儿将牵挂线挂在伞上 | 鞋柜旁 |
| 花坛 | Act 3 | 路人失物的连接端点 | 街道花坛 |

### 角色切换系统

| 元素 | 设计 |
|------|------|
| 切换按键 | Tab |
| 当前角色标识 | ① 角色轮廓发光；② 角色名高亮显示；③ 屏幕边缘出现与角色同色的 subtle 光晕；④ 相机轻微向当前角色偏移 |
| 切换时机 | Act 2 遇到快递柜缺口时首次教学；Act 3 多个机关需要切换 |
| 不可切换时 | 角色处于空中/锚定状态时不可切换 |

## 5.3 环境响应系统

| 牵挂线状态 | 环境响应 |
|-----------|----------|
| Hidden | 世界处于日常状态，无异常 |
| Tense | 共鸣物件发光；画面轻微暗角；出现低频环境音；风铃响动 |
| Adjustable | 环境色温偏暖；锚点物件发出脉动微光；空气中出现暖色光粒子 |
| Extending | 全场景光源柔和变暖；空气中金色光粒子；环境音安静；远处出现微光 |

# 6. 维度三：玩家引导流程

## 6.1 三层引导体系

```
            ┌─────────────────┐
            │   叙事引导层     │  对白暗示角色意图
            └────────┬────────┘
                     │
            ┌────────▼────────┐
            │   环境引导层     │  物件行为暗示行动
            └────────┬────────┘
                     │
            ┌────────▼────────┐
            │   空间引导层     │  光线/几何暗示方向
            └─────────────────┘
```

### 空间引导层

| 引导手段 | 应用场景 | 表现 |
|----------|----------|------|
| 光线引导 | 全关卡 | 关键路径光照亮度比可选路径高 20% |
| 空间收窄 | 章节过渡 | 走廊在关键方向收窄，暗示前进 |
| 色温对比 | 谜题区域 | 目标物件区域偏暖，背景偏冷 |
| 物件高度差 | 女儿房间 | 三件关键物件按由低到高排列，暗示调查顺序 |
| 视觉地标 | 全关卡 | 出口方向有高亮锚点（如远处的光） |

### 环境引导层

| 引导手段 | 应用场景 | 表现 |
|----------|----------|------|
| 牵挂线方向 | Act 1 | 线的走向指向母亲——暗示"回头看" |
| 路灯脉动光 | Act 2 | 可作为锚点的路灯发出脉动暖光 |
| 雨伞呼吸光 | Act 3 | 鞋柜上的雨伞发出呼吸式光效，暗示"来安放线" |
| 花坛微光 | Act 3 | 花坛发出微弱光线，暗示失物端点 |
| 线张力反馈 | Act 1/2 | 拉紧时线抖动+音效，暗示"可以调整" |

### 叙事引导层

| 引导手段 | 应用场景 | 表现 |
|----------|----------|------|
| 母亲自然对白 | Act 1 | "东西都带了吗？"——暗示可以调查物件 |
| 母亲情感对白 | Act 1 | "别走太远。"——暗示距离有影响 |
| 记忆引导对白 | Act 2 | 年幼女儿"我要过去！"——暗示需要操作 |
| 线索对白 | Act 3 | 路人"我的钥匙……好像掉在附近了。"——暗示寻找方向 |
| 情感确认对白 | Act 3 | 母亲"路上小心。"/ 女儿"嗯，妈妈。你也照顾好自己。"——暗示关系转变 |

## 6.2 分阶段教学方案

### 第一幕：发现期
- 玩家自由探索房间。三件物件自然吸引调查。
- 牵挂线在走向门口时自动显现——无文本教学。
- 被拉回是叙事事件，通过对白消解困惑。

### 第二幕：分阶段学习期

| 阶段 | 教学点 | 设计 |
|------|--------|------|
| L02-002 | 推重物 | 先让小女儿在原地等待，玩家单独推自行车，理解"母亲能推重物" |
| L02-003 | 线的张力 | 推完自行车后，小女儿开始往前走，线第一次绷紧，玩家理解"距离影响移动" |
| L02-004 | 角色切换 | 遇到快递柜缺口，提示"按 Tab 切换到小女儿"，小女儿可钻过低矮缺口 |
| L02-005 | 锚点操作 | 路灯发出脉动光，线出现虚线预览，玩家学习绕路灯改变路径 |
| L02-006 | 目送 | 女儿到达终点，母亲站在路灯旁，理解"牵挂可以守护" |

### 第三幕：应用期
- 回到现实后牵挂线呈现新状态（Adjustable）。
- 雨伞呼吸光引导玩家安放线。
- 路人场景：微弱牵挂线自然吸引注意。
- 花坛微光引导寻找失物端点。

### 第四幕：释放期
- 无引导——纯奔跑体验。
- 玩家期待被拉回但线不断——这个"期待落空"即是引导。

## 6.3 新手与高级玩家

### 新手路径
- 无教程文本，全程环境引导
- 每个操作节点有 15-30 秒探索缓冲
- 不可能失败——所有"错误"只是"没有正面反馈"

### 高级玩家保留挑战
| 挑战类型 | 内容 | 奖励 |
|----------|------|------|
| 全收集 | 找到全部记忆碎片 | 结尾牵挂线呈现金色 |
| 全回响 | 站在全部回响点 | 童年记忆增加雨声+哼唱层 |
| 无提示通关 | 在环境提示增强前完成各章节操作 | 隐藏内心独白 |
| 快速通关 | 在 4 分钟内完成全 Demo | 无额外奖励——速度本身即是奖励 |

# 7. 维度四：关卡间过渡衔接

## 7.1 过渡空间设计

### 过渡空间一：伞放置（Act 1 → Act 2）

**剧情衔接**：母亲放下雨伞在鞋柜旁 → 女儿经过时第一次看到牵挂线 → 被拉回 → 注意到雨伞。

**空间特征**：从女儿房间到玄关的走廊。

**设计**：
- 走廊光线从房间内的中性白渐变为玄关的暖黄
- 鞋柜旁的黄色雨伞在走廊尽头可见——视觉地标
- 走廊宽度收窄——暗示"接近出口"
- 母亲在走廊中途停下——暗示"母亲不再同行"

**情绪目标**：好奇 → 受挫 → 注意到雨伞。

### 过渡空间二：记忆褪色（Act 2 → Act 3）

**剧情衔接**：记忆结束 → 画面模糊 → 回到现实玄关。

**空间特征**：记忆画面与现实画面的叠化空间。

**设计**：
- 记忆画面逐渐模糊，雨声渐弱
- 画面从暖黄渐变为正常色温
- 牵挂线重新显现——从 Tense 变为 Adjustable
- 玩家移动控制渐恢复（前 2 秒极慢，之后正常）

**情绪目标**：恍惚、沉淀。

### 过渡空间三：街道延伸（Act 3 → Act 4）

**剧情衔接**：路人找到钥匙 → 女儿继续前行 → 开始奔跑。

**空间特征**：从家门到街道的开阔空间。

**设计**：
- 空间突然开阔——从室内到室外
- 远处有微弱的光——暗示"前方有新的生活"
- 牵挂线在身后——连接家的方向
- 没有阻挡——空间设计暗示"可以跑"

**情绪目标**：开放、期待。

# 8. 维度五：奖励机制配置

## 8.1 三级奖励体系

### L1 即时奖励（每次正确行为后 0-2 秒内）

| 行为 | 奖励 | 表现 |
|------|------|------|
| 调查关键物件 | 叙事碎片 | 短内心独白 + 物件视觉变化 |
| 站上椅子调查相框 | 环境反馈 | 相框微微发光 + 内心独白 |
| 推自行车到指定位置 | 世界反馈 | 自行车靠到墙边，路通 |
| 拉紧牵挂线保护女儿 | 视觉确认 | 线变粗 + 女儿停下 → 安全反馈音 |
| 放松牵挂线给予空间 | 视觉确认 | 线变柔 + 女儿继续前进 + 脚步声 |
| 利用路灯锚点改变路径 | 环境变化 | 线绕过路灯 + 女儿改变方向 + 灯光增强 |
| 将牵挂线挂在雨伞上 | 环境变化 | 线固定在伞上 + 伞轻微发光 + 安心音效 |
| 为路人连接失物 | 世界反馈 | 钥匙发出清脆声音 + 路人循声找到 |

### L2 阶段性奖励（每幕完成后）

| 阶段 | 奖励 | 表现 |
|------|------|------|
| Act 1 完成 | 认知奖励 | 玩家理解核心意象——"原来这就是关系" |
| Act 2 完成 | 机制奖励 | 玩家理解"牵挂可以调整"——线状态变为 Adjustable |
| Act 3 完成 | 情感奖励 | 玩家理解"牵挂属于世界"——世界因连接恢复完整 |
| Act 4 完成 | 主题奖励 | 玩家理解"牵挂允许远行"——线成为余响 |

### L3 终局奖励（完成 Demo 后）

| 条件 | 奖励 |
|------|------|
| 基础通关 | 标准结尾——牵挂线银色，柔和延伸 |
| 收集全部碎片 | 增强结尾——牵挂线金色，更温暖 |
| 无提示通关 | 隐藏内心独白："原来这根线，一直都在。" |
| 全探索 | 童年记忆增加一段雨声+哼唱层 |

## 8.2 奖励与叙事的融合原则

1. **不使用数值奖励**：没有分数、经验值、成就弹窗
2. **奖励即叙事**：每个奖励是情感/认知层面的确认
3. **渐进式温暖**：随着玩家行为累积，场景光照和音效逐渐变暖
4. **不惩罚失败**：错误操作不产生负面反馈，只产生"没有正面反馈"
5. **世界因你而完整**：第三章路人寻物的奖励是"世界恢复完整"——不是个人获得

# 10. 验收标准

## 10.1 难度曲线验收

- [ ] 五段式递进清晰可辨（探索→单项机制→组合机制→应用→释放）
- [ ] 每段难度来源不同（认知→操作→推理→情感）
- [ ] 无两段连续高难度区间
- [ ] 第二章操作零失败——女儿被挡住只是停下

## 10.2 交互验收

- [ ] 12 种交互类型均可正常触发
- [ ] 牵挂线四态系统在不同章节有明确区分
- [ ] 锚点操作在第二章可学习、在第三章可应用
- [ ] 记忆碎片可被收集且不阻塞流程
- [ ] 回响点不需要任何 UI 提示即可被发现
- [ ] 角色切换有明确的四重视觉标识

## 10.3 引导验收

- [ ] 新玩家在无教程文本情况下可完成全流程
- [ ] 关键路径出口在进入每个区域 3 秒内可被识别
- [ ] 第二章锚点操作有环境引导（路灯脉动光 + 虚线预览）
- [ ] 第三章花坛钥匙有视觉引导（微弱光线）
- [ ] 高级玩家可发现至少 1 个可选挑战

## 10.4 过渡验收

- [ ] 3 个过渡空间均存在且可感知
- [ ] 章节间情绪转换连贯
- [ ] 视角切换有预判信号（色温变化+角色模型变化）
- [ ] 记忆回归后有情绪缓冲空间

## 10.5 奖励验收

- [ ] 每个正确行为有即时反馈
- [ ] 阶段性奖励在叙事上有意义
- [ ] 终局奖励在探索程度上有差异
- [ ] 无任何数值化/游戏化奖励弹窗
- [ ] 第三章路人寻物的奖励是"世界恢复完整"而非个人获得

## 10.6 叙事一致性验收

- [ ] 牵挂线四态与剧情理解阶段对齐
- [ ] 四幕主题分别对应：束缚→可调→世界→远行
- [ ] 黄色雨伞在四幕中承担不同功能（记忆入口→锚点→情感象征）
- [ ] 母亲角色在四幕分别呈现：照顾者→保护者→放手者→释然者
- [ ] 女儿角色在四幕分别呈现：被束缚者→理解者→连接者→远行者
