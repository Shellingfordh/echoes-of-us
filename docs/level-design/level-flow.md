# 关卡流程｜Level 01

## 1. 关卡目标

关卡名称：

> Level 01｜不断线

目标时长：

> 3～5 分钟

本关需要完成四件事：

1. 建立母女关系；
2. 教会玩家牵挂线；
3. 让玩家使用牵挂线解决一个简单谜题；
4. 通过黄色雨伞进入记忆并完成情绪收束。

---

# 3. 节点定义

## L01-001｜Start

**触发：**

游戏启动。

**玩家状态：**

允许移动。

**场景状态：**

母女位于同一空间。

**目标：**

不立即给玩家教程。

玩家首先观察环境和母女关系。

**完成条件：**

玩家移动超过起始区域。

---

## L01-002｜同行

**触发：**

玩家开始移动。

**事件：**

母亲保持在玩家附近。

**对白：**

D001～D003。

**玩家反馈：**

通过角色动作建立关系。

**设计要求：**

不要让母亲像敌人一样跟随玩家。

她应该表现为：

> 自然地同行。

---

## L01-003｜TieLine Reveal

**触发：**

玩家与母亲距离超过 RevealDistance。

**事件：**

牵挂线第一次出现。

**玩家控制：**

保持。

**镜头：**

轻微聚焦，不强制切镜。

**对白：**

D010～D011。

**完成条件：**

玩家观察牵挂线并继续移动。

---

## L01-004｜Tension Tutorial

**触发：**

Distance >= TensionThreshold。

**事件：**

牵挂线进入 Tense。

视觉变化：

- 线宽增加；
- 颜色变化；
- 轻微抖动；
- 音效变化。

**对白：**

D020。

**失败处理：**

不允许真正失败。

玩家继续移动时，线进入强张力状态，并产生轻微反馈。

随后通过关卡设计让玩家自然回到安全范围。

---

## L01-005｜Puzzle Area

玩家进入核心谜题区域。

场景包含：

- Memory Door；
- Object A；
- Object B；
- Object C；
- Yellow Umbrella。

---

## L01-006｜Memory Lock

**目标：**

通过牵挂线连接 A → B → C。

**玩家行为：**

1. 观察环境；
2. 尝试连接；
3. 获得视觉/音效反馈；
4. 完成正确顺序。

**成功条件：**

A → B → C 正确连接，并保持连接 2 秒。

**失败条件：**

连续错误 3 次。

**失败反馈：**

不 Game Over。

门短暂关闭并恢复初始状态。

---

## L01-007｜Yellow Umbrella

谜题完成后，黄色雨伞变为可交互对象。

**触发：**

玩家进入 InteractionRange。

**UI：**

显示轻量交互提示。

**触发后：**

- 玩家控制锁定；
- 环境音降低；
- 黄色雨伞成为视觉焦点；
- 播放 D040；
- 开始记忆转场。

---

## L01-008｜Memory Transition

转场目标：

> 当前空间 → 童年记忆。

建议表现：

1. 黄色雨伞特写；
2. 雨声出现；
3. 环境色温变化；
4. 当前场景与记忆场景叠化；
5. Camera 平滑移动；
6. 玩家进入记忆状态。

玩家无需重新加载复杂流程即可获得“现实被记忆覆盖”的感觉。

---

## L01-009｜Childhood Memory

玩家暂时无法自由探索。

以短演出为主：

```text
母亲撑伞
↓
童年女儿走在旁边
↓
母亲将伞向女儿倾斜
↓
雨声
↓
画面停留
```

持续时间建议：

> 30～60 秒。

不要加入复杂交互。

---

## L01-010｜Return

回到现实。

环境恢复。

牵挂线重新出现。

但视觉状态发生变化：

> 从强张力变成稳定、柔和。

---

## L01-011｜Ending

女儿向出口移动。

母亲停在原地。

玩家继续走。

距离逐渐增加。

牵挂线：

```text
Normal
↓
Long Distance
↓
Stable
```

而不是：

```text
Normal
↓
Broken
```

最后淡出。

# 4. 玩家控制状态

| 状态 | 可移动 | 可交互 | 可触发剧情 |
|---|---:|---:|---:|
| Normal | Yes | Yes | Yes |
| Dialogue | No/视对白 | No | No |
| MemoryTransition | No | No | No |
| Memory | No | No | No |
| Ending | Yes | No | Yes |

具体实现方式由技术决定。

---

# 5. 关卡验收

完成关卡必须满足：

- 玩家能在 10 秒内理解基础移动；
- 第一次看到牵挂线时不会产生明显困惑；
- 玩家能够通过反馈理解距离与张力；
- 核心谜题无需文字答案；
- 黄色雨伞能自然成为记忆入口；
- 记忆演出不超过整体时长预算；
- 结尾明确表达“关系没有断”。

---

# 6. 不做事项

本 Demo 不加入：

- 战斗；
- 复杂背包；
- 多角色战斗 AI；
- 大地图；
- 复杂任务树；
- 随机生成；
- 多结局。

任何新增机制必须首先确认是否直接服务于本关主题。
