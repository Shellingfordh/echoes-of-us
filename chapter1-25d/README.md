# 第一章 2.5D 独立工程

这是从最新 `main` 文档重新建立的第一章主体工程，和仓库现有 `game/` 原型相互独立。

## 运行

```bash
godot --path chapter1-25d
```

操作：

```text
WASD / 方向键  在房间的横向与纵深方向移动
E / Enter       调查、进入或退出固定观察
Esc             退出固定观察
R               第一章完成后重新开始
```

自动验证：

```bash
godot --headless --path chapter1-25d --script res://scripts/tests/smoke_test.gd
```

## 为什么这是 2.5D

- 场景、家具、角色和牵挂线均位于真实 `Node3D` 空间；
- 玩家使用 `CharacterBody3D`，可以在 X/Z 两个地面轴移动；
- 墙体、床、衣柜、书桌、纸箱、行李箱和木凳使用 `StaticBody3D` 阻挡角色，并保留前后景绕行通道；
- 使用正交 `Camera3D`，保持绘本式构图，同时保留前景、中景、后景的真实遮挡与视差；
- 牵挂线由多段 3D Mesh 构成，从余念手部连接到楼下母亲；
- 镜头只做缓慢跟随、固定观察推进和轻量张力反馈，不使用 FPS 式运动。

## 最新文档口径

工程明确采用以下统一结果：

1. P1 必须完成五件调查：纸箱、行李箱、书桌、床底耳机、柜顶相框；没有 30 秒跳过。
2. 衣柜、窗玻璃为 P1 选调；木凳用于够到相框。
3. 固定观察用于窗玻璃、耳机和相框；相框按最新 SR-002 画成普通春游合影，不使用“手悬在肩膀上”的象征姿势。
4. P2 保留行李箱二次调查 D045 与黄伞调查 D046。
5. P3 让普通线状物变红，并提供 D047。
6. 张力由距离、冲突情绪和离开意图共同构成，不向玩家显示数值条。
7. 第一次极限张力产生回弹；第二次尝试证明线可以承重并形成有限摆动。
8. 第一章结束在黄伞与红线触发余响的位置，不提前制作第二章。
