## 本章产品目标

玩家在离家前的日常空间里认识余念、母亲留下的生活痕迹和双方边界冲突；章节结束时，玩家应确认牵挂线真实存在、会限制距离并产生物理阻力，同时和余念一起形成一个不完整判断：妈妈不想让我走。

第一章只建立束缚感。承重、悬挂、摆荡和“线托住人”的意义反转必须留到第二章七岁余念坠落时。

## 当前流程与健康度

1. 进入房间，理解移动与调查。状态：已去掉常驻计数，目标改为生活化的离家前确认；剩余三件以上继续自由探索，进入最后两件后才逐步给出位置线索。
2. 调查五件必要物件，并用木凳解锁柜顶相框。状态：保留策划指定的五件主调查；已补齐 O-ID 客观信息 → D-ID 人物反应、“相框高度障碍 → 木凳真实移位 → 相框解锁”的空间因果，以及最后两件 / 最后一件 / 正在确认最后一件的状态反馈。
3. 母亲进入，围绕黄色旧雨伞发生冲突。状态：十个策划对白 ID 保持原文与顺序，连续同角色动作已按六个情绪段落同屏呈现；真实阅读节奏仍需真人试玩验证。
4. 玩家再次尝试离开，牵挂线显形并第一次强制回弹。状态：首次显线已用双端点镜头同时展示余念、母亲和完整连线，并从余念掌心展开；张力升高时角色姿态与房间细线同步出现非颜色反馈。
5. 玩家主动抓线并向门口用力，确认真实物理阻力。状态：D015 / D016 反应完整结束后才开放抓线；角色前倾、影子受压和地面回拉共同表达阻力，不提前消耗第二章承重反转。
6. 普通线状物产生克制视觉呼应，玩家再次离开失败。状态：本轮已校正；普通线不再统一变红发光。
7. 余念得出“妈妈不想让我走”的错误理解，黄伞与红线共同激活后进入余响。状态：D018 后即使物理阻力解除，红线仍保持余响红色，黄伞与线同步呼吸；触伞后先锁定约 0.8 秒共同激活演出，再进入 2009 年秋标题。

## 已发现并处理的问题

### P0｜第一章提前展示承重，破坏第二章意义反转

旧实现让余念在第一章被线吊起并左右摆荡，等于提前教学“线能托住人”。这与最新章节边界冲突，也会让第二章坠落被救失去第一次发生的冲击。

处理：删除第一章悬空流程，改成“抓住线 + 向门口用力 + 地面回拉”；增加 `chapter1_physical_resistance_confirmed` 状态与全程逻辑 Y 为 0 的回归断言。

### P1｜固定观察看起来像离开房间进入图鉴

旧实现以大面积浅色卡片和重遮罩覆盖房间，削弱“同一空间换位置看”的主题。

处理：改为右侧半透明深色观察面板，背景只做轻度压暗，保留角色、房间和物件空间关系；同步最新 O-ID 客观信息与 D-ID 主观反应。

### P1｜对白内容落后于最新策划

旧 D017 仍是“它托得住我”，D001–D004、D041–D047 也有多处旧版客观描述与角色态度混写。

处理：对白 JSON 同步最新对白表；D017 改为确认真实阻力，且不再自动串到 D018，D018 只在玩家再次离开失败后触发。

### P1｜普通线状物被统一染红，误导世界规则

旧实现把胶带边、耳机线、缝纫线等全部染成红色，容易让玩家认为所有线都是超自然物。

处理：只有牵挂线发光并提供物理反馈；普通线只保留低强度中性色提示。

### P1｜目标更新先淡出，关键操作提示短暂不可读

旧目标组件每次先用 0.35 秒完全淡出，再换字并淡入；抓线等即时教学状态会出现提示已经开始、文字仍不可读的窗口。

处理：目标文字立即更新，只从 62% 透明度快速淡入，不再先黑屏；同时移除初始“0/5”计数。

### P1｜普通调查直接播放独白，事实与态度混在一起

旧实现点击纸箱、行李箱或书桌后直接播放余念独白，策划要求的 O-ID 客观信息完全缺失。玩家既看不到关键票面时间和摆放差异，也难以判断哪些话是世界事实、哪些只是余念的态度。

处理：新增统一物件信息层和 `object_info.json`。纸箱、行李箱、书桌、男式外套、黄伞与普通线都先显示无角色署名的 O-ID，再进入对应 D-ID；固定观察也改为从同一数据源读取。流程测试保证最后一件物品的 O/D 两层都结束前，母亲不会提前进场。

### P1｜搬木凳没有可见位移，相框解锁缺少因果反馈

旧实现中，玩家站在相框正下方时直接看到“移动木凳”，但没有先确认相框为何不能调查；按下交互后木凳仍停在原地，只通过顶部文案和相框轻微高亮表示成功。玩家能执行答案，却看不到自己的动作怎样改变了房间。

处理：不可调查的相框现在可提供只读障碍提示，且不会吞掉真正的空交互；走近木凳后才切换到动作提示。交互后木凳用 0.32 秒移动到衣柜边，2D 画面与隐藏 `StaticBody3D` 碰撞同步更新，落位后才开放相框、显示观察提示并更新目标。自动化覆盖提示优先级、真实位移、碰撞位置与相框解锁顺序。

### P1｜去掉计数后，探索尾部只剩“再四处看看”

旧实现虽然去掉了游戏化的 `0/5`，但调查三件后仍只显示“房间还没完全收好。再四处看看”，剩最后一件也只显示“还有一处没确认”。更严重的是，玩家打开第五件物品时目标仍写“还有一处”，和当前状态直接冲突。

处理：建立五件主调查的稳定生活化线索表。剩三件以上保持自由探索；剩两件时同时提示两个空间锚点；剩一件时明确最后目标；第五件已经打开后改为“把眼前这件东西看完”。不恢复数字计数，也不在探索早期展示清单。流程测试覆盖五个提示映射、两件 / 一件 / 零件剩余状态和最后一件内容结束前不提前触发黄伞冲突。

### P1｜十个单句对白屏把黄伞冲突切成机械翻页

旧实现把 D005-D014 每个策划 ID 都当成一个独立阻塞屏。正常阅读需要十次确认，玩家要到第六次确认后才看见真正的情绪问题 D011；同一角色连续完成的一次表达也被拆成两次翻页，操作节拍盖过了冲突节拍。

处理：保留全部对白 ID、正文和连接顺序，只增加表现层分组。D005-D006、D007-D008、D009-D010、D013-D014 分别同屏，D011 与 D012 保持独立，形成“照料开场 → 女儿设限 → 母亲施压 → 真正问题 → 转移到雨伞 → 母亲退让”六段。玩家仍手动确认，不引入自动倒计时；到达 D011 从六次确认降到三次，完整结束从十次降到六次。流程测试断言六屏包含的原始 ID，防止后续改文案时误删或乱序。

同轮实机截图发现 D011 的“远”被默认字体显示为缺字方框；已为全部 UI 顶层控件补充中文系统字体回退列表，保证情绪转折句可读。字体仍取自运行平台，正式发行前需要随素材授权一起确定并内置一致字体。

### P0｜首次显线看不到母亲端点，回弹反应与抓线教学发生竞态

旧实现沿用跟随玩家的门口构图，第一次显线时整根线直接伸出画面左侧，玩家看不到另一端的母亲，无法从画面确认“牵挂线连接具体的人”。回弹后只要张力降到重置阈值，流程就会在 D015“怎么又回来了？”仍显示时切到抓线教学；顶部目标、底部按键提示和独白同时出现，玩家此时按交互还能直接进入挑战，使 D016“……线？”被打断。

处理：新增独立显线节拍和 `LineRevealView`。离开触发后短暂收住操作，镜头用 0.45 秒移动到母女双端点构图，牵挂线用 0.9 秒从余念掌心展开，1.35 秒后再恢复玩家继续向门口的行动。第一次回弹后，流程必须等 D015 → D016 整段反应结束且张力已回落，才显示“抓住牵挂线”并开放主动试探。流程测试同时断言显线阶段锁定、源端展开、D015 / D016 顺序、提示延后和最终抓线入口。

### P1｜张力变化只在线上发生，角色身体没有“受阻”

优化前的普通、张紧和主动试探截图中，线会从青色变黄、变红并逐渐拉直，但余念的身体、脚下影子和周围生活线在三种状态里几乎完全相同。即使玩家实际移动速度已经下降，静态画面仍像角色站着看一条变色的线，SR-005 / SR-006 要求的“行动越来越困难”和“身体被带动”主要由文字说明承担。

处理：不新增素材，直接让现有角色资产随实际阻力连续变化。远离且张力升高时，余念逐步向行动方向前倾；极限回拉和主动对抗时，身体偏移、轻微颤动，地面影子压低并横向加宽，始终保持脚下支撑。房间中已有的胶带边、耳机线、缝纫线等只做最多 2.4 像素的中性扰动，不改变颜色或发光属性。流程测试断言主动试探时角色和环境反馈均已达到可见强度。

### P1｜触碰黄伞直接切标题，“共同激活”只存在于文案

优化前，D018 出现时红线会绷紧变红，但玩家回到黄伞旁后，物理张力降低会让线恢复普通青色；触碰黄伞又会在同一帧完成第一章并开始标题淡入。玩家能从任务文字知道下一步，却看不到策划要求的“黄伞与红线共同触发余响”，容易把黄伞理解成独立传送按钮。

处理：把物理张力与余响共鸣拆成两个状态。接近黄伞后物理回拉正常解除，但红线继续以红色、宽度和曲率脉冲表达余响；黄伞沿用现有高亮层，以同一绝对时间相位同步呼吸，不新增人与物之间的线。触碰黄伞后先锁定约 0.8 秒，强化二者同步共鸣，再完成第一章并淡入 `余响 / 2009 年秋`。流程测试断言共同共鸣、同步相位、物理阻力解除、短演出未结束前章节不得完成，以及最终转场。

## 仍需持续回答的产品问题

1. 五件主调查已经由最新策划明确保留；仍需验证玩家是否能从五件物品分别得到不可替代的信息，而不是只感到推进门槛。
2. 木凳解锁相框是叙事动作，还是轻解谜？当前路径已经用高度障碍、木凳动作和落位反馈表达；仍需验证首次玩家能否在不看攻略的情况下完成，且不会把它误解成“站上去”的操作挑战。
3. P1 应是自由探索还是明确教学？当前采用“前半段自由、最后两件渐进提示”的折中；仍需验证两个空间锚点是否足够可见，以及最后一件提示会不会显得过于直接。
4. 黄色旧雨伞冲突从十次确认收敛到六个情绪段落后，是否既保留停顿又不显拖沓？需要用 3–5 名首次玩家测量各段阅读时长、跳过倾向和 D011 情绪转折理解率。
5. 玩家现在可通过线宽 / 曲率、角色前倾、影子受压和环境细线扰动理解张力；仍需验证这些变化是否足够明显，并补充声音或手柄震动等跨感官反馈。
6. 首次显线的 0.45 秒镜头移动和 1.35 秒观察窗是否足够看清且不会造成晕动不适？仍需真人验证，并为正式版补充减少镜头运动选项。
7. 黄伞与红线的约 0.8 秒共同激活是否足以建立因果、又不会显得拖延？需要首次玩家复述“是什么触发了余响”，并观察是否有人仍把黄伞理解为单独传送按钮。

## 下一轮建议顺序

1. 做 3–5 名首次玩家测试，记录进入最后两件后首次注意到目标文字的时间、完成剩余调查的耗时、错误尝试和是否需要口头提示。
2. 同轮记录“发现相框 → 找到木凳 → 完成观察”、P1 总探索时长、六段黄伞对白的完成率 / 阅读时长 / 快速跳过率，以及抓线交互成功率，判断渐进提示、五件门槛与冲突节奏是否合适。
3. 增加木凳拖动声、牵挂线张力 / 余响共鸣声音与可关闭的手柄震动，以及按键重映射 / 手柄提示和减少镜头运动选项，补足跨感官与可访问性反馈。

## 可访问性与证据限制

- 本轮余响共鸣同时改变线宽、曲率和黄伞高亮尺寸，不只依赖红 / 青颜色差；但仍需做色觉模拟与低对比度实机检查。
- 当前没有“减少动态效果”开关。同步呼吸幅度较小且不闪白，但其舒适度、光敏风险和 0.8 秒锁定节奏不能由静态截图证明，必须真人测试。
- 键盘主流程已由自动化覆盖；手柄提示、按键重映射、声音 / 震动替代反馈和辅助技术可理解性仍未验证，不能据此宣称完整无障碍合规。
- 截图能证明构图、颜色与状态顺序，不能证明玩家是否真正理解“共同触发”；该理解率仍需 3–5 名首次玩家复述验证。
