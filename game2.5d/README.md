# `game2.5d` 等距 2.5D 原型工程

`game2.5d/` 是《余响：牵挂》的独立 Godot 原型工程，用于验证等距 2.5D 空间、第一章基础流程与牵挂线物理反馈。工程可以直接运行，不依赖仓库中的其他游戏目录。

## 工程信息

- 引擎：Godot 4.7 或更高版本；
- 主场景：`scenes/main/main.tscn`；
- 输出：1280×720，16:9；
- 表现：2D 等距画面配合隐藏的 3D 角色、家具碰撞；
- 物理：Jolt Physics。

## 当前内容

- 第一章房间与 P1/P2/P3 基础流程；
- 五件必要调查物：纸箱、行李箱、书桌、床底耳机、柜顶相框；
- 衣柜、窗户、木珠串、行李箱二查、黄伞和普通线状物等可选内容；
- `data/observations.json` 中的 11 条 O-ID 客观信息；
- `data/dialogues.json` 中的角色对白与反应；
- 移动木凳后解锁柜顶相框；
- 黄伞冲突、牵挂线显现、张力递进、强制回弹与地面阻力；
- 等距移动、3D 家具阻挡、遮挡排序与固定观察界面；
- 第一章结束后进入“2009 年秋”的余响转场。

第一章只表现牵挂线的回拉和阻力，不进入承重、悬挂或摆荡玩法。

## 运行

在仓库根目录执行：

```bash
godot --path game2.5d
```

首次检出工程、准备直接运行无头测试时，先完成一次资源导入和全局类注册：

```bash
godot --headless --editor --path game2.5d --quit
```

## 操作

- WASD / 方向键：移动；
- Enter / 空格：调查、推进对白；
- Esc：退出固定观察；
- F3：显示或隐藏调试信息。

## 验证

```bash
godot --headless --path game2.5d --script res://tests/smoke_25d.gd
godot --headless --path game2.5d --script res://tests/chapter01_flow_test.gd
```

`smoke_25d.gd` 验证等距移动、碰撞、遮挡排序和基础数据；`chapter01_flow_test.gd` 验证第一章阶段、调查、对白、回弹与结束条件。

## 目录

- `art/`：原型图片、音乐和音效；
- `data/`：对白与观察信息；
- `scenes/`：主场景、房间、角色与 UI；
- `scripts/`：空间投影、角色控制、交互、剧情流程与牵挂线；
- `tests/`：冒烟测试、第一章流程测试和截图脚本。

## 素材状态

`art/` 中的资源用于内部原型验证，目前没有完整的来源与授权记录。正式发行、公开演示或对外分发前，需要补齐许可信息或替换为项目自有素材。

## 维护边界

本目录保留为原始 `game2.5d` 基线。后续若维护该原型，应只修改 `game2.5d/` 内的场景、脚本、数据与说明，并使用本目录自己的运行和测试命令。
